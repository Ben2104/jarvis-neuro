# Viewer (Plan B of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the browser viewer in `frontend/`. It loads a baked case (`index.json`, `manifest.json`, `case.glb`, two `.bin` volumes), renders the patient's brain surface and tumour sub-regions in 3D, links them to a 2D MRI slice panel, and exposes every scene tool through a validated executor that keyboard shortcuts, gestures and (in Plan C) the agent WebSocket all call.

**Architecture:** Pure TypeScript modules hold all geometry and logic: the zod manifest mirror, affine math, volume slicing, the case loader, the tool schemas and executor, the gesture reducer and shortcut mapping. Each has vitest tests running in Node against the committed `synth_001` fixture. One zustand store holds the view state. Thin React and `@react-three/fiber` components read the store and render it. The browser never computes a clinical number; it shows manifest values and derives screen positions only through `vox2ras`, its inverse, and `ras2gl`.

**Tech Stack:** Vite 8.3.4, React 19.3.1, TypeScript 6.0.3, three 0.186.1, @react-three/fiber 9.8.2, @react-three/drei 10.7.9, @mediapipe/tasks-vision 1.1.1, zod 4.6.7, zustand 5.0.15, vitest 5.0.5. Node 22.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-17-jarvis-neuro-design.md`. §4 manifest, §5 tools, §6 frontend, §7 errors, §8 tests.
- Every number shown in the UI comes from `manifest.json` (spec decision 5). Formatting and rounding are allowed. Sums of manifest volumes are allowed and labelled as sums. Hemisphere is allowed, derived from `centroid_ras[0]` vs `midline_x_ras`. Nothing else is derived.
- No named anatomy anywhere in the UI (spec decision 1). Hover and labels use asset ids (`tumor_et`, `brain_surface`) plus the MSD label meaning (1 edema, 2 non-enhancing tumor, 3 enhancing tumor). No "Motor strip", no lobes.
- No placeholder clinical values in the UI. Missing data renders as `—`.
- Load `case.glb` with three's `GLTFLoader` plus `DRACOLoader`. Scale the case root group by `0.001` (mm → scene units).
- Render order: opaque tumour sub-regions first, translucent tumour sub-regions next, `brain_surface` last. `brain_surface` defaults to opacity `0.45`, `depthWrite: false`, `side: FrontSide`, with a Fresnel rim.
- `tumor_ed` defaults to opacity `0.35`. It is a shell around the core (Plan A "Next plans") and hides the inner regions when opaque. `tumor_et` and `tumor_ncr` default to `1.0`.
- Cutaway and hemisphere hiding use per-material `clippingPlanes` with `renderer.localClippingEnabled = true`. Hemisphere hiding clips `brain_surface` only, at `midline_x_ras`. Cutaway clips every asset.
- Gestures (spec §6): per-frame pinch state lives in a `useRef`, never React state; selection fires on the pinch rising edge only; picking never hits `brain_surface`; every asset gets its own material instance. Mapping: open hand = rotate, pinch = select, two hands = zoom.
- Tool arguments are validated with zod. Unknown `asset_id`s and unknown keys are rejected. Numeric ranges are clamped. Results are `{id, ok: true, result}` or `{id, ok: false, error}`.
- Every tool the browser executes has a keyboard shortcut.
- §7 errors: a failed manifest, volume or GLB fetch, or a schema failure, shows an error banner and keeps the previous case loaded. Webcam denied or unavailable falls back to mouse and keyboard with a visible message.
- The footer shows "Educational visualization — not for diagnosis or surgical planning." and the dataset attribution "Medical Segmentation Decathlon, Task01_BrainTumour (derived from BraTS), CC BY-SA 4.0".
- 2D slice display convention (radiological, to be re-checked on a real MSD case per spec §9): axial and coronal show patient right on screen left; axial shows anterior at the top; coronal and sagittal show superior at the top; sagittal shows anterior on the left. All of it lives in `slicePixelToVoxel` / `voxelToSlicePixel` so one edit flips it.
- Theme tokens and layout come from the mockup (`https://claude.ai/artifact/Dv2dBD77PWE6JrzWnantHv`): IBM Plex Sans / IBM Plex Mono, grid `340px | 1fr | 372px`, gap 12, padding 12, header 52px, footer 36px. The mockup's "Explode" button and placeholder volumes are not built.
- All commands run from `frontend/` unless stated. Commit messages use conventional commits. Add your own agent attribution trailer if your harness requires one.
- Work on branch `feat/plan-b-viewer`, created from `feat/plan-a-bake`. Never commit to `main`.

## Out of scope for Plan B (Plan C does these)

The FastAPI WebSocket client, the agent text input wiring, speech-to-text and text-to-speech, and `explain`. Plan B leaves `executeTool(store, call, source)` as the single entry point that the Plan C WebSocket client calls, and exposes it in dev as `window.__jarvis`.

## Reference values for `synth_001` (used in tests)

`dims [56,64,48]`, `vox2ras` = diag(3,3,3) with translation `(-81,-96,-72)`, `ras2gl` = `(x,y,z) → (−x, z, y)`, `midline_x_ras 0`. Each mask/flair `.bin` is `56*64*48 = 172032` bytes. All three tumours have `centroid_ras [-24, 18, 3]` → voxel `(19, 38, 25)`. Asset order in the manifest: `brain_surface`, `tumor_et`, `tumor_ncr`, `tumor_ed`. Volumes 13.014, 6.939, 18.36 mL. The GLB has four mesh nodes named like the assets, `POSITION` only (no normals), and every mesh shares one default material after loading.

```js
import { cpSync, existsSync, mkdirSync, writeFileSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'

const root = join(dirname(fileURLToPath(import.meta.url)), '..')
const pub = join(root, 'public')

  'https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task'

cpSync(join(root, 'node_modules/three/examples/jsm/libs/draco/gltf'), join(pub, 'draco'), { recursive: true })
cpSync(join(root, 'node_modules/@mediapipe/tasks-vision/wasm'), join(pub, 'mediapipe/wasm'), { recursive: true })

const model = join(pub, 'mediapipe/hand_landmarker.task')
if (!existsSync(model)) {
  try {
    const res = await fetch(MODEL_URL)
    if (!res.ok) throw new Error(`HTTP ${res.status}`)
    mkdirSync(dirname(model), { recursive: true })
    writeFileSync(model, Buffer.from(await res.arrayBuffer()))
    console.log('vendor: downloaded hand_landmarker.task')
  } catch (err) {
    console.warn(`vendor: could not download ${MODEL_URL} (${err.message}); gestures stay unavailable until it exists`)
  }
}
console.log('vendor: draco decoder and mediapipe wasm copied into public/')
```

```ts
import { existsSync, readFileSync } from 'node:fs'
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'

export const FRONTEND_DIR = fileURLToPath(new URL('../../', import.meta.url))
export const PUBLIC_DIR = join(FRONTEND_DIR, 'public')
export const SYNTH_DIR = join(PUBLIC_DIR, 'cases/synth_001/synthetic')
export const SHARED_SCHEMA_PATH = join(FRONTEND_DIR, '..', 'shared', 'manifest.schema.json')

// eslint-style escape hatch: fixtures are untyped JSON that tests mutate on purpose.
// eslint-disable-next-line @typescript-eslint/no-explicit-any
export function readJson(path: string): any {
  return JSON.parse(readFileSync(path, 'utf8'))
}

// eslint-disable-next-line @typescript-eslint/no-explicit-any
export function readSynthManifestJson(): any {
  return readJson(join(SYNTH_DIR, 'manifest.json'))
}

export function readSynthBytes(file: string): Uint8Array {
  return new Uint8Array(readFileSync(join(SYNTH_DIR, file)))
}

/**
 * A fetch that serves URL paths from frontend/public. `overrides` is read at call
 * time, so a test can break one URL after a successful first load.
 */
export function fsFetch(overrides: Record<string, () => Response> = {}): typeof fetch {
  return (async (input: RequestInfo | URL) => {
    const url = typeof input === 'string' ? input : input instanceof URL ? input.pathname : input.url
    const override = overrides[url]
    if (override) return override()
    const file = join(PUBLIC_DIR, url)
    if (!existsSync(file)) return new Response('not found', { status: 404 })
    return new Response(new Uint8Array(readFileSync(file)))
  }) as typeof fetch
}
```

```ts
import { z } from 'zod'

// Mirror of shared/manifest.schema.json (generated by backend pydantic models).
// manifest.test.ts checks key-for-key parity; change both sides together.

export const TUMOR_IDS = ['tumor_et', 'tumor_ncr', 'tumor_ed'] as const
export type TumorId = (typeof TUMOR_IDS)[number]
/** Value written into mask_u8.bin for each tumour asset (MSD convention). */
export const LABEL_BY_TUMOR: Record<TumorId, 1 | 2 | 3> = { tumor_et: 3, tumor_ncr: 2, tumor_ed: 1 }
export const PROVENANCES = ['ground-truth', 'monai-segresnet', 'synthetic'] as const
export type Provenance = (typeof PROVENANCES)[number]

const Vec3Schema = z.tuple([z.number(), z.number(), z.number()])
const Mat4Schema = z.array(z.number()).length(16)
const CaseIdSchema = z.string().regex(/^[a-z0-9_]+$/)

export const SurfaceAssetSchema = z.strictObject({
  id: z.literal('brain_surface'),
  node: z.string(),
  kind: z.literal('surface'),
})

export const TumorAssetSchema = z.strictObject({
  id: z.enum(TUMOR_IDS),
  label: z.union([z.literal(1), z.literal(2), z.literal(3)]),
  node: z.string(),
  kind: z.literal('tumor'),
  color: z.string().regex(/^#[0-9A-Fa-f]{6}$/),
  volume_ml: z.number().min(0),
  centroid_ras: Vec3Schema,
  bbox_ras: z.tuple([Vec3Schema, Vec3Schema]),
  min_dist_surface_mm: z.number().min(0),
})

export const VolumesSchema = z.strictObject({ flair: z.string(), mask: z.string() })

export const MetricsSchema = z.strictObject({
  dice_vs_gt: z.record(z.string(), z.number()).nullable().default(null),
```

```ts
import type { Manifest, Vec3 } from './manifest'

/** 4x4 matrix, 16 numbers, row-major (same layout as manifest.vox2ras / ras2gl). */
export type Mat4 = number[]
export type Dims = [number, number, number]

/** Manifest geometry is in millimetres; the scene is in metres. */
export const SCENE_SCALE = 0.001

export interface CaseFrame {
  dims: Dims
  vox2ras: Mat4
  ras2vox: Mat4
  ras2gl: Mat4
  gl2ras: Mat4
}

export function invert4(m: Mat4): Mat4 {
  // Gauss-Jordan with partial pivoting on [m | I].
  const a = Array.from({ length: 4 }, (_, r) => [
    ...m.slice(r * 4, r * 4 + 4),
    ...[0, 1, 2, 3].map((c) => (c === r ? 1 : 0)),
  ])
  for (let col = 0; col < 4; col++) {
    let pivot = col
    for (let r = col + 1; r < 4; r++) if (Math.abs(a[r][col]) > Math.abs(a[pivot][col])) pivot = r
    if (Math.abs(a[pivot][col]) < 1e-12) throw new Error('matrix is singular')
    ;[a[col], a[pivot]] = [a[pivot], a[col]]
    const p = a[col][col]
    for (let c = 0; c < 8; c++) a[col][c] /= p
    for (let r = 0; r < 4; r++) {
      if (r === col) continue
      const f = a[r][col]
      if (f !== 0) for (let c = 0; c < 8; c++) a[r][c] -= f * a[col][c]
    }
  }
  return a.flatMap((row) => row.slice(4))
}

export function multiply4(a: Mat4, b: Mat4): Mat4 {
  const out = new Array<number>(16).fill(0)
  for (let r = 0; r < 4; r++)
    for (let c = 0; c < 4; c++) for (let k = 0; k < 4; k++) out[r * 4 + c] += a[r * 4 + k] * b[k * 4 + c]
  return out
}

export function applyAffine(m: Mat4, p: Vec3): Vec3 {
  return [0, 1, 2].map((r) => m[r * 4] * p[0] + m[r * 4 + 1] * p[1] + m[r * 4 + 2] * p[2] + m[r * 4 + 3]) as Vec3
}

/** Rotation/scale part only (for directions). */
export function applyLinear(m: Mat4, v: Vec3): Vec3 {
  return [0, 1, 2].map((r) => m[r * 4] * v[0] + m[r * 4 + 1] * v[1] + m[r * 4 + 2] * v[2]) as Vec3
}

export function makeFrame(m: Pick<Manifest, 'dims' | 'vox2ras' | 'ras2gl'>): CaseFrame {
  return {
    dims: [...m.dims] as Dims,
    vox2ras: [...m.vox2ras],
    ras2vox: invert4(m.vox2ras),
    ras2gl: [...m.ras2gl],
    gl2ras: invert4(m.ras2gl),
  }
}

export function voxelToRas(f: CaseFrame, v: Vec3): Vec3 {
  return applyAffine(f.vox2ras, v)
}

export function rasToVoxel(f: CaseFrame, ras: Vec3): Vec3 {
  return applyAffine(f.ras2vox, ras)
}

export function rasToVoxelIndex(f: CaseFrame, ras: Vec3): Vec3 | null {
  const v = rasToVoxel(f, ras).map(Math.round) as Vec3
  return v.every((x, i) => x >= 0 && x < f.dims[i]) ? v : null
}

export function rasToScene(f: CaseFrame, ras: Vec3): Vec3 {
  return applyAffine(f.ras2gl, ras).map((x) => x * SCENE_SCALE) as Vec3
}

export function sceneToRas(f: CaseFrame, p: Vec3): Vec3 {
  return applyAffine(f.gl2ras, p.map((x) => x / SCENE_SCALE) as Vec3)
}

export function voxelSpacing(f: CaseFrame): Vec3 {
  return [0, 1, 2].map((c) => Math.hypot(f.vox2ras[c], f.vox2ras[4 + c], f.vox2ras[8 + c])) as Vec3
}

export function rasExtent(f: CaseFrame): { min: Vec3; max: Vec3 } {
  const min: Vec3 = [Infinity, Infinity, Infinity]
  const max: Vec3 = [-Infinity, -Infinity, -Infinity]
  for (const i of [0, f.dims[0] - 1])
    for (const j of [0, f.dims[1] - 1])
      for (const k of [0, f.dims[2] - 1]) {
        const p = voxelToRas(f, [i, j, k])
        for (let a = 0; a < 3; a++) {
          min[a] = Math.min(min[a], p[a])
          max[a] = Math.max(max[a], p[a])
        }
      }
  return { min, max }
}
```

```ts
import type { Dims } from './affine'
import type { Vec3 } from './manifest'

export const AXES = ['axial', 'coronal', 'sagittal'] as const
export type Axis = (typeof AXES)[number]

/** Voxel dimension the slice index walks (volumes are canonical: i→R, j→A, k→S). */
export const AXIS_DIM: Record<Axis, 0 | 1 | 2> = { sagittal: 0, coronal: 1, axial: 2 }
/** RAS component a slice of this axis holds constant. */
export const RAS_DIM: Record<Axis, 0 | 1 | 2> = { sagittal: 0, coronal: 1, axial: 2 }

export class Volume {
  readonly dims: Dims
  readonly data: Uint8Array

  constructor(dims: Dims, data: Uint8Array) {
    const expected = dims[0] * dims[1] * dims[2]
    if (data.length !== expected) {
      throw new RangeError(`volume has ${data.length} bytes, expected ${expected} (${dims.join('x')})`)
    }
    this.dims = dims
    this.data = data
  }

  offset(i: number, j: number, k: number): number {
    return (i * this.dims[1] + j) * this.dims[2] + k
  }

  get(i: number, j: number, k: number): number {
    return this.data[this.offset(i, j, k)]
  }
}

export function sliceShape(dims: Dims, axis: Axis): { width: number; height: number } {
  if (axis === 'axial') return { width: dims[0], height: dims[1] }
  if (axis === 'coronal') return { width: dims[0], height: dims[2] }
  return { width: dims[1], height: dims[2] }
}

export function sliceCount(dims: Dims, axis: Axis): number {
  return dims[AXIS_DIM[axis]]
}

// Radiological display. Change these two functions (and SLICE_EDGE_LABELS) together.
export function slicePixelToVoxel(dims: Dims, axis: Axis, index: number, col: number, row: number): Vec3 {
  if (axis === 'axial') return [dims[0] - 1 - col, dims[1] - 1 - row, index]
  if (axis === 'coronal') return [dims[0] - 1 - col, index, dims[2] - 1 - row]
  return [index, dims[1] - 1 - col, dims[2] - 1 - row]
}

export function voxelToSlicePixel(dims: Dims, axis: Axis, v: Vec3): { col: number; row: number; index: number } {
  if (axis === 'axial') return { col: dims[0] - 1 - v[0], row: dims[1] - 1 - v[1], index: v[2] }
  if (axis === 'coronal') return { col: dims[0] - 1 - v[0], row: dims[2] - 1 - v[2], index: v[1] }
  return { col: dims[1] - 1 - v[1], row: dims[2] - 1 - v[2], index: v[0] }
}

export const SLICE_EDGE_LABELS: Record<Axis, { left: string; right: string; top: string; bottom: string }> = {
  axial: { left: 'R', right: 'L', top: 'A', bottom: 'P' },
  coronal: { left: 'R', right: 'L', top: 'S', bottom: 'I' },
  sagittal: { left: 'A', right: 'P', top: 'S', bottom: 'I' },
}

export function extractSlice(vol: Volume, axis: Axis, index: number): Uint8Array {
  const count = sliceCount(vol.dims, axis)
  if (!Number.isInteger(index) || index < 0 || index >= count) {
    throw new RangeError(`${axis} slice ${index} out of range 0..${count - 1}`)
  }
  const { width, height } = sliceShape(vol.dims, axis)
  const out = new Uint8Array(width * height)
  for (let row = 0; row < height; row++)
    for (let col = 0; col < width; col++) {
      const [i, j, k] = slicePixelToVoxel(vol.dims, axis, index, col, row)
      out[row * width + col] = vol.get(i, j, k)
    }
  return out
}
```

```ts
import { type CaseFrame, rasToVoxel, voxelToRas } from './affine'
import type { TumorAsset, Vec3 } from './manifest'
import {
  type Axis,
  AXIS_DIM,
  RAS_DIM,
  type Volume,
  extractSlice,
  slicePixelToVoxel,
  sliceShape,
  voxelToSlicePixel,
} from './volume'

export type RGB = [number, number, number]

export interface SliceImage {
  width: number
  height: number
  rgba: Uint8ClampedArray<ArrayBuffer>
}

export function hexToRgb(hex: string): RGB {
  const n = parseInt(hex.slice(1), 16)
  return [(n >> 16) & 255, (n >> 8) & 255, n & 255]
}

/** Grey FLAIR; a mask pixel whose label is in `outline` and differs from a 4-neighbour is drawn in colour. */
export function renderSlice(flair: Volume, mask: Volume, axis: Axis, index: number, outline: Map<number, RGB>): SliceImage {
  const { width, height } = sliceShape(flair.dims, axis)
  const grey = extractSlice(flair, axis, index)
  const labels = extractSlice(mask, axis, index)
  const rgba = new Uint8ClampedArray(width * height * 4)
  const at = (col: number, row: number) =>
    col < 0 || row < 0 || col >= width || row >= height ? -1 : labels[row * width + col]
  for (let row = 0; row < height; row++)
    for (let col = 0; col < width; col++) {
      const p = row * width + col
      const label = labels[p]
      const color = label > 0 ? outline.get(label) : undefined
      const edge =
        color !== undefined &&
        (at(col - 1, row) !== label || at(col + 1, row) !== label || at(col, row - 1) !== label || at(col, row + 1) !== label)
      const [r, g, b] = edge && color ? color : [grey[p], grey[p], grey[p]]
      rgba[p * 4] = r
      rgba[p * 4 + 1] = g
      rgba[p * 4 + 2] = b
      rgba[p * 4 + 3] = 255
    }
  return { width, height, rgba }
}

export function outlineColors(tumors: TumorAsset[], visible: Record<string, boolean>): Map<number, RGB> {
  return new Map(tumors.filter((t) => visible[t.id] !== false).map((t) => [t.label, hexToRgb(t.color)]))
}

/** Fractional slice pixel and slice index of a RAS point (for the crosshair). */
export function markerToSlicePixel(f: CaseFrame, axis: Axis, ras: Vec3): { col: number; row: number; index: number } {
  return voxelToSlicePixel(f.dims, axis, rasToVoxel(f, ras))
}

export function slicePointToRas(f: CaseFrame, axis: Axis, index: number, col: number, row: number): Vec3 {
  return voxelToRas(f, slicePixelToVoxel(f.dims, axis, index, col, row))
}

/** RAS coordinate (mm) the slice holds constant, measured at the slice's first voxel. */
export function sliceRasMm(f: CaseFrame, axis: Axis, index: number): number {
  const v: Vec3 = [0, 0, 0]
  v[AXIS_DIM[axis]] = index
  return voxelToRas(f, v)[RAS_DIM[axis]]
}
```

```ts
import type { Mesh, Object3D } from 'three'
import { parseGlb as defaultParseGlb } from '../scene/gltf'
import { type CaseFrame, makeFrame } from './affine'
import {
  type CaseIndex,
  type CaseIndexEntry,
  CaseIndexSchema,
  type Manifest,
  ManifestSchema,
  formatIssues,
} from './manifest'
import { Volume } from './volume'

export const CASES_ROOT = '/cases/'

export interface CaseDeps {
  fetchFn?: typeof fetch
  root?: string
  parseGlb?: (buffer: ArrayBuffer) => Promise<Object3D>
}

export class CaseLoadError extends Error {
  override name = 'CaseLoadError'
}

export interface LoadedCase {
  entry: CaseIndexEntry
  manifest: Manifest
  baseUrl: string
  glbUrl: string
  frame: CaseFrame
  flair: Volume
  mask: Volume
  scene: Object3D
}

const messageOf = (e: unknown) => (e instanceof Error ? e.message : String(e))

async function getBytes(fetchFn: typeof fetch, url: string): Promise<Uint8Array<ArrayBuffer>> {
  let res: Response
  try {
    res = await fetchFn(url)
  } catch (e) {
    throw new CaseLoadError(`could not fetch ${url}: ${messageOf(e)}`)
  }
  if (!res.ok) throw new CaseLoadError(`HTTP ${res.status} for ${url}`)
  return new Uint8Array(await res.arrayBuffer())
}

async function getJson(fetchFn: typeof fetch, url: string): Promise<unknown> {
  const bytes = await getBytes(fetchFn, url)
  try {
    return JSON.parse(new TextDecoder().decode(bytes))
  } catch {
    throw new CaseLoadError(`${url} is not JSON`)
  }
}

function toVolume(frame: CaseFrame, bytes: Uint8Array, url: string): Volume {
  try {
    return new Volume(frame.dims, bytes)
  } catch (e) {
    throw new CaseLoadError(
      `${url}: ${messageOf(e)}. If the file is stored gzip-compressed, serve it with Content-Encoding: gzip.`,
    )
  }
}

function assertAssetNodes(manifest: Manifest, scene: Object3D, glbUrl: string) {
  for (const asset of manifest.assets) {
    const node = scene.getObjectByName(asset.node) as Mesh | undefined
    if (!node?.isMesh) throw new CaseLoadError(`asset ${asset.id}: no mesh named "${asset.node}" in ${glbUrl}`)
  }
}

export async function fetchIndex(deps: CaseDeps = {}): Promise<CaseIndex> {
  const fetchFn = deps.fetchFn ?? globalThis.fetch.bind(globalThis)
  const url = `${deps.root ?? CASES_ROOT}index.json`
  const parsed = CaseIndexSchema.safeParse(await getJson(fetchFn, url))
  if (!parsed.success) throw new CaseLoadError(`${url} invalid: ${formatIssues(parsed.error)}`)
  return parsed.data
}

export async function fetchCase(entry: CaseIndexEntry, deps: CaseDeps = {}): Promise<LoadedCase> {
  const fetchFn = deps.fetchFn ?? globalThis.fetch.bind(globalThis)
  const parse = deps.parseGlb ?? defaultParseGlb
  const manifestUrl = `${deps.root ?? CASES_ROOT}${entry.path}`
  const baseUrl = manifestUrl.slice(0, manifestUrl.lastIndexOf('/') + 1)

  const parsed = ManifestSchema.safeParse(await getJson(fetchFn, manifestUrl))
  if (!parsed.success) throw new CaseLoadError(`manifest invalid: ${formatIssues(parsed.error)}`)
  const manifest = parsed.data
  if (manifest.case_id !== entry.case_id || manifest.provenance !== entry.provenance) {
    throw new CaseLoadError(
      `${manifestUrl} is ${manifest.case_id}/${manifest.provenance}, index says ${entry.case_id}/${entry.provenance}`,
    )
  }

  const frame = makeFrame(manifest)
  const flairUrl = baseUrl + manifest.volumes.flair
  const maskUrl = baseUrl + manifest.volumes.mask
  const glbUrl = baseUrl + manifest.glb
  const [flairBytes, maskBytes, glbBytes] = await Promise.all([
    getBytes(fetchFn, flairUrl),
    getBytes(fetchFn, maskUrl),
    getBytes(fetchFn, glbUrl),
  ])
  const flair = toVolume(frame, flairBytes, flairUrl)
  const mask = toVolume(frame, maskBytes, maskUrl)

  let scene: Object3D
  try {
    scene = await parse(glbBytes.buffer)
  } catch (e) {
    throw new CaseLoadError(`could not parse glTF ${glbUrl}: ${messageOf(e)}`)
  }
  assertAssetNodes(manifest, scene, glbUrl)

  return { entry, manifest, baseUrl, glbUrl, frame, flair, mask, scene }
}
```

```ts
  name: string

  args: unknown
  ok: boolean
  text: string
  at: number

  brain_surface: 0.45,
  tumor_et: 1,
  tumor_ncr: 1,
  tumor_ed: 0.35,

  index: CaseIndex | null
  current: LoadedCase | null
  loading: boolean
  error: string | null

  visible: Record<string, boolean>

  loadIndex(): Promise<void>
  loadCase(caseId: string, provenance?: Provenance): Promise<LoadCaseResult>
  setOpacity(id: string, value: number): void
  setVisible(ids: string[], visible: boolean): void
  setCutaway(plane: CutPlane, rasMm: number): void
  setHemisphere(side: Hemisphere): void

  setWebcam(patch: Partial<ViewerState['webcam']>): void

export function clampIndex(index: number, count: number): number {
  return Math.min(count - 1, Math.max(0, index))
}

export function sliceIndexThrough(frame: CaseFrame, axis: Axis, ras: Vec3): number {
  return clampIndex(Math.round(rasToVoxel(frame, ras)[AXIS_DIM[axis]]), sliceCount(frame.dims, axis))

  ViewerState,
  'opacity' | 'visible' | 'cutaway' | 'hemisphere' | 'slice' | 'marker' | 'selected' | 'hovered'
>

export function initialViewFor(loaded: LoadedCase): InitialView {
  const ids = loaded.manifest.assets.map((a) => a.id)
  const first = tumorAssets(loaded.manifest)[0]
  const marker: Vec3 | null = first ? [...first.centroid_ras] : null
  const axis: Axis = 'axial'
  return {
    opacity: Object.fromEntries(ids.map((id) => [id, DEFAULT_OPACITY[id] ?? 1])),
    visible: Object.fromEntries(ids.map((id) => [id, true])),
    cutaway: { plane: 'none', rasMm: 0 },
    hemisphere: 'none',
    slice: {
      axis,
      index: marker
        ? sliceIndexThrough(loaded.frame, axis, marker)
        : Math.floor(sliceCount(loaded.frame.dims, axis) / 2),
    },
    marker,
    selected: null,
    hovered: null,
  }
}

const messageOf = (e: unknown) => (e instanceof Error ? e.message : String(e))

export function createViewerStore(deps: CaseDeps = {}): ViewerStore {
  let loadSeq = 0
  return createStore<Viewer>()((set, get) => ({
    index: null,
    current: null,
    loading: false,
    error: null,
    opacity: {},
    visible: {},
    cutaway: { plane: 'none', rasMm: 0 },
    hemisphere: 'none',
    slice: { axis: 'axial', index: 0 },
    marker: null,
    selected: null,
    hovered: null,
    focus: { assetId: 'brain_surface', nonce: 0 },
    toolLog: [],
    gesturesOn: false,
    webcam: { status: 'off', hands: 0, error: null },

    async loadIndex() {
      try {
        set({ index: await fetchIndex(deps) })
      } catch (e) {
        set({ error: `could not load the case index: ${messageOf(e)}` })
      }
    },

    async loadCase(caseId, provenance) {
      const index = get().index
      const entry = index?.cases.find(
        (c) => c.case_id === caseId && (provenance === undefined || c.provenance === provenance),
      )
      if (!entry) {
        const error = index ? `unknown case ${caseId}${provenance ? ` (${provenance})` : ''}` : 'case index not loaded'
        set({ error })
        return { ok: false, error }
      }
      const token = ++loadSeq
      set({ loading: true })
      try {
        const loaded = await fetchCase(entry, deps)
        if (token !== loadSeq) return { ok: false, error: 'superseded by a newer load_case' }
        set((s) => ({
          current: loaded,
          loading: false,
          error: null,
          ...initialViewFor(loaded),
          focus: { assetId: 'brain_surface', nonce: s.focus.nonce + 1 },
        }))
        return { ok: true, loaded }
      } catch (e) {
        const error = `could not load ${caseId}: ${messageOf(e)}`
        if (token === loadSeq) set({ loading: false, error })
        return { ok: false, error }
      }
    },

    setOpacity: (id, value) => set((s) => ({ opacity: { ...s.opacity, [id]: value } })),
    setVisible: (ids, visible) =>
      set((s) => ({ visible: { ...s.visible, ...Object.fromEntries(ids.map((id) => [id, visible])) } })),
    setCutaway: (plane, rasMm) => set({ cutaway: { plane, rasMm } }),
    setHemisphere: (hemisphere) => set({ hemisphere }),
    setSlice: (axis, index) => set({ slice: { axis, index } }),
    setMarker: (marker) => set({ marker }),

    select(id) {
      const { current, slice } = get()
      const tumor = current && id ? tumorAssets(current.manifest).find((t) => t.id === id) : undefined
      if (!current || !tumor) {
        set({ selected: id })
        return
      }
      const marker: Vec3 = [...tumor.centroid_ras]
      set({
        selected: id,
        marker,
        slice: { axis: slice.axis, index: sliceIndexThrough(current.frame, slice.axis, marker) },
      })
    },

    hover(id) {
      if (get().hovered !== id) set({ hovered: id })
    },
    requestFocus: (assetId) => set((s) => ({ focus: { assetId, nonce: s.focus.nonce + 1 } })),
    logTool: (entry) => set((s) => ({ toolLog: [...s.toolLog, entry].slice(-TOOL_LOG_CAP) })),
    dismissError: () => set({ error: null }),
    setGesturesOn: (gesturesOn) => set({ gesturesOn }),
    setWebcam: (patch) => set((s) => ({ webcam: { ...s.webcam, ...patch } })),
  }))
}

export const viewerStore = createViewerStore()

export function useViewer<T>(selector: (s: Viewer) => T): T {
  return useStore(viewerStore, selector)
}
```

```ts
import { z } from 'zod'
import { rasExtent } from '../lib/affine'
import type { LoadedCase } from '../lib/loadCase'
import { type CaseIndex, PROVENANCES, type Provenance } from '../lib/manifest'
import { AXES, type Axis, RAS_DIM, sliceCount } from '../lib/volume'
import { type CutPlane, type Hemisphere, clampIndex } from '../state/store'

/** Spec §5 tools the browser executes. `explain` runs in the backend (Plan C). */
export const TOOL_NAMES = [
  'load_case',
  'set_opacity',
  'focus_region',
  'set_cutaway',
  'hide_hemisphere',
  'toggle_visibility',
  'inspect_mri_slice',
] as const
export type ToolName = (typeof TOOL_NAMES)[number]
export type CaseToolName = Exclude<ToolName, 'load_case'>

export const CUT_PLANES = ['axial', 'coronal', 'sagittal', 'none'] as const satisfies readonly CutPlane[]
export const HEMISPHERES = ['left', 'right', 'none'] as const satisfies readonly Hemisphere[]

export function isToolName(name: string): name is ToolName {
  return (TOOL_NAMES as readonly string[]).includes(name)
}

/** Arguments after validation and clamping. */
export interface ToolArgs {
  load_case: { case_id: string; provenance?: Provenance }
  set_opacity: { asset_id: string; value: number }
  focus_region: { asset_id: string }
  set_cutaway: { plane: CutPlane; ras_mm: number }
  hide_hemisphere: { side: Hemisphere }
  toggle_visibility: { asset_ids: string[]; visible: boolean }
  inspect_mri_slice: { axis: Axis; index: number }
}

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v))

function oneOf(allowed: string[], what: string) {
  return z.string().refine((v) => allowed.includes(v), {
    error: (issue) => `unknown ${what} ${JSON.stringify(issue.input)}; expected one of ${allowed.join(', ')}`,
  })
}

export function makeLoadCaseSchema(index: CaseIndex | null): z.ZodType<ToolArgs['load_case']> {
  const caseIds = [...new Set(index?.cases.map((c) => c.case_id) ?? [])]
  return z.strictObject({ case_id: oneOf(caseIds, 'case_id'), provenance: z.enum(PROVENANCES).optional() })
}

export function makeCaseToolSchemas(c: LoadedCase): { [K in CaseToolName]: z.ZodType<ToolArgs[K]> } {
  const assetId = oneOf(
    c.manifest.assets.map((a) => a.id),
    'asset_id',
  )
  const extent = rasExtent(c.frame)
  return {
    set_opacity: z.strictObject({ asset_id: assetId, value: z.number().transform((v) => clamp(v, 0, 1)) }),
    focus_region: z.strictObject({ asset_id: assetId }),
    set_cutaway: z
      .strictObject({ plane: z.enum(CUT_PLANES), ras_mm: z.number().optional() })
      .transform((a, ctx) => {
        if (a.plane === 'none') return { plane: a.plane, ras_mm: 0 }
        if (a.ras_mm === undefined) {
          ctx.issues.push({ code: 'custom', message: 'ras_mm is required unless plane is none', input: a, path: ['ras_mm'] })
          return z.NEVER
        }
        const d = RAS_DIM[a.plane]
        return { plane: a.plane, ras_mm: clamp(a.ras_mm, extent.min[d], extent.max[d]) }
      }),
    hide_hemisphere: z.strictObject({ side: z.enum(HEMISPHERES) }),
    toggle_visibility: z.strictObject({ asset_ids: z.array(assetId).min(1), visible: z.boolean() }),
    inspect_mri_slice: z
      .strictObject({ axis: z.enum(AXES), index: z.number() })
      .transform((a) => ({ axis: a.axis, index: clampIndex(Math.round(a.index), sliceCount(c.frame.dims, a.axis)) })),
  }
}
```

```ts
import type { z } from 'zod'
import type { LoadedCase } from '../lib/loadCase'
import { formatIssues, hemisphereOf } from '../lib/manifest'
import { sliceRasMm } from '../lib/slice'
import { extractSlice, sliceCount } from '../lib/volume'
import type { ToolSource, ViewerStore } from '../state/store'
import { TOOL_NAMES, isToolName, makeCaseToolSchemas, makeLoadCaseSchema } from './schemas'

export interface ToolCall {
  id: string
  name: string
  args: unknown
}

export type ToolResult = { id: string; ok: true; result: unknown } | { id: string; ok: false; error: string }

let callCounter = 0
export function newCallId(prefix: string): string {
  callCounter += 1
  return `${prefix}-${Date.now().toString(36)}-${callCounter}`
}

/** What load_case returns: manifest values only, plus the hemisphere derived from centroid x vs midline. */
export function caseSummary(c: LoadedCase) {
  const m = c.manifest
  return {
    case_id: m.case_id,
    provenance: m.provenance,
    dims: m.dims,
    midline_x_ras: m.midline_x_ras,
    assets: m.assets.map((a) =>
      a.kind === 'tumor'
        ? {
            id: a.id,
            kind: a.kind,
            label: a.label,
            volume_ml: a.volume_ml,
            centroid_ras: a.centroid_ras,
            bbox_ras: a.bbox_ras,
            min_dist_surface_mm: a.min_dist_surface_mm,
            hemisphere: hemisphereOf(a.centroid_ras[0], m.midline_x_ras),
          }
        : { id: a.id, kind: a.kind },
    ),
    dice_vs_gt: m.metrics.dice_vs_gt,
  }
}

type Parsed<T> = { ok: true; value: T } | { ok: false; error: string }

function parseArgs<T>(schema: z.ZodType<T>, args: unknown): Parsed<T> {
  const r = schema.safeParse(args ?? {})
  return r.success ? { ok: true, value: r.data } : { ok: false, error: `invalid arguments: ${formatIssues(r.error)}` }
}

async function run(store: ViewerStore, call: ToolCall): Promise<ToolResult> {
  const ok = (result: unknown): ToolResult => ({ id: call.id, ok: true, result })
  const fail = (error: string): ToolResult => ({ id: call.id, ok: false, error })
  const name = call.name
  if (!isToolName(name)) return fail(`unknown tool ${name}; browser tools are ${TOOL_NAMES.join(', ')}`)
  const s = store.getState()

  if (name === 'load_case') {
    const a = parseArgs(makeLoadCaseSchema(s.index), call.args)
    if (!a.ok) return fail(a.error)
    const r = await s.loadCase(a.value.case_id, a.value.provenance)
    return r.ok ? ok(caseSummary(r.loaded)) : fail(r.error)
  }

  const current = s.current
  if (!current) return fail('no case loaded; call load_case first')
  const schemas = makeCaseToolSchemas(current)

  switch (name) {
    case 'set_opacity': {
      const a = parseArgs(schemas.set_opacity, call.args)
      if (!a.ok) return fail(a.error)
      s.setOpacity(a.value.asset_id, a.value.value)
      return ok(a.value)
    }
    case 'focus_region': {
      const a = parseArgs(schemas.focus_region, call.args)
      if (!a.ok) return fail(a.error)
      const asset = current.manifest.assets.find((x) => x.id === a.value.asset_id)!
      s.requestFocus(asset.id)

        index,

        ras_mm: sliceRasMm(current.frame, axis, index),
        labels_present: [...labels].sort((x, y) => x - y),

  }
}
```

```ts
import { Color, DoubleSide, FrontSide, MeshStandardMaterial } from 'three'
import type { Asset } from '../lib/manifest'

export const BRAIN_COLOR = '#C9D3D8'
export const RIM_COLOR = '#5BC0CE'
export const BASE_EMISSIVE = 0.08
export const HOVER_EMISSIVE = 0.55
export const SELECTED_EMISSIVE = 0.3

/** View-dependent rim (spec §6 "Fresnel rim"): brighter and more opaque where the surface turns away. */
export function addFresnelRim(mat: MeshStandardMaterial, color = RIM_COLOR, power = 2.5): void {
  mat.onBeforeCompile = (shader) => {
    shader.uniforms.uRimColor = { value: new Color(color) }
    shader.uniforms.uRimPower = { value: power }
    shader.fragmentShader = shader.fragmentShader
      .replace('#include <common>', '#include <common>\nuniform vec3 uRimColor;\nuniform float uRimPower;')
      .replace(
        '#include <opaque_fragment>',
        [
          'float rim = pow(1.0 - abs(dot(normalize(normal), normalize(vViewPosition))), uRimPower);',
          'outgoingLight += uRimColor * rim;',
          'diffuseColor.a = clamp(diffuseColor.a + rim * 0.5, 0.0, 1.0);',
          '#include <opaque_fragment>',
        ].join('\n'),
      )
  }
  mat.customProgramCacheKey = () => 'fresnel-rim'
}

export function createAssetMaterial(asset: Asset): MeshStandardMaterial {
  if (asset.kind === 'surface') {
    const mat = new MeshStandardMaterial({
      color: BRAIN_COLOR,
      roughness: 0.6,
      metalness: 0,
      transparent: true,
      opacity: 0.45,
      depthWrite: false,
      side: FrontSide,
    })
    addFresnelRim(mat)
    return mat
  }
  return new MeshStandardMaterial({
    color: asset.color,
    emissive: asset.color,
    emissiveIntensity: BASE_EMISSIVE,
    roughness: 0.45,
    metalness: 0,
    side: DoubleSide,
  })
}

export function applyOpacity(mat: MeshStandardMaterial, asset: Asset, opacity: number): void {
  const transparent = asset.kind === 'surface' || opacity < 1
  if (mat.transparent !== transparent) {
    mat.transparent = transparent
    mat.needsUpdate = true
  }
  mat.opacity = opacity
  mat.depthWrite = !transparent
}

/** Opaque tumours first, translucent tumours next, brain_surface last (spec §6). */
export function renderOrderFor(asset: Asset, opacity: number): number {
  if (asset.kind === 'surface') return 2
  return opacity < 1 ? 1 : 0
}
```

```ts
import { Plane, Vector3 } from 'three'
import { type CaseFrame, applyLinear, rasToScene } from '../lib/affine'
import type { Vec3 } from '../lib/manifest'
import { RAS_DIM } from '../lib/volume'
import type { CutPlane, Hemisphere } from '../state/store'

/** three keeps fragments where plane.distanceToPoint(p) >= 0; `keepRas` is the RAS normal of the kept side. */
function planeKeeping(f: CaseFrame, keepRas: Vec3, pointRas: Vec3): Plane {
  const normal = new Vector3(...applyLinear(f.ras2gl, keepRas)).normalize()
  return new Plane().setFromNormalAndCoplanarPoint(normal, new Vector3(...rasToScene(f, pointRas)))
}

/** Removes everything with RAS coordinate on the plane's axis greater than rasMm. */
export function cutawayPlane(f: CaseFrame, plane: Exclude<CutPlane, 'none'>, rasMm: number): Plane {
  const keep: Vec3 = [0, 0, 0]
  const point: Vec3 = [0, 0, 0]
  keep[RAS_DIM[plane]] = -1
  point[RAS_DIM[plane]] = rasMm
  return planeKeeping(f, keep, point)
}

/** Removes the named hemisphere (left = RAS x below the midline). Applied to brain_surface only. */
export function hemispherePlane(f: CaseFrame, side: Exclude<Hemisphere, 'none'>, midlineX: number): Plane {
  return planeKeeping(f, [side === 'left' ? 1 : -1, 0, 0], [midlineX, 0, 0])
}
```

```ts
import { Group, type Material, type Mesh, type MeshStandardMaterial } from 'three'
import { SCENE_SCALE } from '../lib/affine'
import type { LoadedCase } from '../lib/loadCase'
import { createAssetMaterial } from './materials'

export interface PreparedCase {
  root: Group
  meshes: Map<string, Mesh>
  materials: Map<string, MeshStandardMaterial>
  tumorMeshes: Mesh[]
}

const prepared = new WeakMap<LoadedCase, PreparedCase>()

/** Idempotent per LoadedCase (React StrictMode renders twice). */
export function prepareCase(c: LoadedCase): PreparedCase {
  const hit = prepared.get(c)
  if (hit) return hit

  const root = new Group()
  root.name = `case:${c.manifest.case_id}:${c.manifest.provenance}`
  root.scale.setScalar(SCENE_SCALE)
  root.add(c.scene)

  const meshes = new Map<string, Mesh>()
  const materials = new Map<string, MeshStandardMaterial>()
  const tumorMeshes: Mesh[] = []
  const replaced = new Set<Material>()

  for (const asset of c.manifest.assets) {
    const mesh = c.scene.getObjectByName(asset.node) as Mesh
    if (!mesh.geometry.getAttribute('normal')) mesh.geometry.computeVertexNormals()
    for (const m of Array.isArray(mesh.material) ? mesh.material : [mesh.material]) replaced.add(m)
    const mat = createAssetMaterial(asset)
    mesh.material = mat
    mesh.userData.assetId = asset.id
    if (asset.kind === 'surface') {
      // Gesture fix 3: rays pass through the brain to the tumours inside it.
      mesh.raycast = () => {}
    } else {
      tumorMeshes.push(mesh)
    }
    meshes.set(asset.id, mesh)
    materials.set(asset.id, mat)
  }
  for (const m of replaced) m.dispose()

  const result = { root, meshes, materials, tumorMeshes }
  prepared.set(c, result)
  return result
}

export function releaseCase(c: LoadedCase): void {
  const p = prepared.get(c)
  if (!p) return
  for (const mesh of p.meshes.values()) mesh.geometry.dispose()
  for (const mat of p.materials.values()) mat.dispose()
  p.root.removeFromParent()
  p.root.clear()
  prepared.delete(c)
}
```

```ts
import type { Plane } from 'three'
import type { LoadedCase } from '../lib/loadCase'
import type { ViewerState } from '../state/store'
import { cutawayPlane, hemispherePlane } from './clipping'
import { BASE_EMISSIVE, HOVER_EMISSIVE, SELECTED_EMISSIVE, applyOpacity, renderOrderFor } from './materials'
import type { PreparedCase } from './prepare'

export type SceneView = Pick<ViewerState, 'opacity' | 'visible' | 'cutaway' | 'hemisphere' | 'hovered' | 'selected'>

export function applyViewState(p: PreparedCase, c: LoadedCase, v: SceneView): void {
  const cut = v.cutaway.plane === 'none' ? null : cutawayPlane(c.frame, v.cutaway.plane, v.cutaway.rasMm)
  const hemi = v.hemisphere === 'none' ? null : hemispherePlane(c.frame, v.hemisphere, c.manifest.midline_x_ras)

  for (const asset of c.manifest.assets) {
    const mesh = p.meshes.get(asset.id)!
    const mat = p.materials.get(asset.id)!
    const opacity = v.opacity[asset.id] ?? 1
    applyOpacity(mat, asset, opacity)
    mesh.renderOrder = renderOrderFor(asset, opacity)
    mesh.visible = v.visible[asset.id] !== false && opacity > 0

    const planes = [cut, asset.kind === 'surface' ? hemi : null].filter((x): x is Plane => x !== null)
    mat.clippingPlanes = planes.length > 0 ? planes : null

    if (asset.kind === 'tumor') {
      mat.emissiveIntensity =
        asset.id === v.hovered ? HOVER_EMISSIVE : asset.id === v.selected ? SELECTED_EMISSIVE : BASE_EMISSIVE
    }
  }
}
```

```ts
import type { Material, Object3D, Raycaster, Vector3 } from 'three'
import type { PreparedCase } from './prepare'

export interface PickHit {
  assetId: string
  point: Vector3
}

/** True when a world-space hit point lies on the removed side of one of the object's clipping planes. */
export function isClippedAway(object: Object3D, point: Vector3): boolean {
  const planes = (object as { material?: Material }).material?.clippingPlanes ?? []
  return planes.some((plane) => plane.distanceToPoint(point) < 0)
}

/** Nearest visible tumour hit that is not clipped away. brain_surface is never hit. */
export function pickTumor(raycaster: Raycaster, p: PreparedCase): PickHit | null {
  const visible = p.tumorMeshes.filter((m) => m.visible)
  for (const hit of raycaster.intersectObjects(visible, false)) {
    if (!isClippedAway(hit.object, hit.point)) return { assetId: hit.object.userData.assetId as string, point: hit.point }
  }
  return null
}
```

```ts
/** Normalised device coordinates: x right, y up, both in -1..1. */
export type NdcPoint = [number, number]

export type GestureEvent =
  | { type: 'hover'; ndc: NdcPoint }
  | { type: 'select'; ndc: NdcPoint }
  | { type: 'rotate'; dx: number; dy: number }
  | { type: 'zoom'; scale: number }
  | { type: 'lost' }

export function createBus<E>() {
  const listeners = new Set<(e: E) => void>()
  return {
    on(fn: (e: E) => void): () => void {
      listeners.add(fn)
      return () => {
        listeners.delete(fn)
      }
    },
    emit(e: E): void {
      for (const fn of listeners) fn(e)
    },
  }
}

/** Per-frame gesture events. Never mirrored into React state. */
export const gestureBus = createBus<GestureEvent>()
```

```tsx
import type { ThreeEvent } from '@react-three/fiber'
import { useLayoutEffect, useMemo } from 'react'
import type { LoadedCase } from '../lib/loadCase'
import { useViewer, viewerStore } from '../state/store'
import { isClippedAway } from './picking'
import { prepareCase } from './prepare'
import { applyViewState } from './viewState'

const assetIdOf = (e: ThreeEvent<PointerEvent | MouseEvent>) => (e.object.userData.assetId as string | undefined) ?? null

export function CaseModel({ loaded }: { loaded: LoadedCase }) {
  const prepared = useMemo(() => prepareCase(loaded), [loaded])
  const opacity = useViewer((s) => s.opacity)
  const visible = useViewer((s) => s.visible)
  const cutaway = useViewer((s) => s.cutaway)
  const hemisphere = useViewer((s) => s.hemisphere)
  const hovered = useViewer((s) => s.hovered)
  const selected = useViewer((s) => s.selected)

  useLayoutEffect(() => {
    applyViewState(prepared, loaded, { opacity, visible, cutaway, hemisphere, hovered, selected })
  }, [prepared, loaded, opacity, visible, cutaway, hemisphere, hovered, selected])

  // brain_surface has raycast disabled, so these only ever see tumour meshes. A hit on the
  // clipped-away side is ignored without stopPropagation, so r3f offers the event to the next hit.
  const onPointerMove = (e: ThreeEvent<PointerEvent>) => {
    if (isClippedAway(e.object, e.point)) return
    e.stopPropagation()
    viewerStore.getState().hover(assetIdOf(e))
  }
  const onPointerOut = () => viewerStore.getState().hover(null)
  const onClick = (e: ThreeEvent<MouseEvent>) => {
    if (isClippedAway(e.object, e.point)) return
    e.stopPropagation()
    viewerStore.getState().select(assetIdOf(e))
  }

  return <primitive object={prepared.root} onPointerMove={onPointerMove} onPointerOut={onPointerOut} onClick={onClick} />
}
```

```tsx
import { CameraControls } from '@react-three/drei'
import { type ComponentRef, useEffect, useRef } from 'react'
import { Vector3 } from 'three'
import { gestureBus } from '../gestures/bus'
import { useViewer } from '../state/store'
import { assetBox } from './focus'
import { prepareCase } from './prepare'

/**
 * Radians per NDC unit of hand travel. Mouse dragging in camera-controls is
 * rotate(-2π·Δx/height, -2π·Δy/height) with Δy pointing down; NDC spans 2 units and points up,
 * so the hand equivalent is rotate(-dx·π, +dy·π).
 */
export const ROTATE_GAIN = Math.PI

export function CameraRig() {
  const ref = useRef<ComponentRef<typeof CameraControls>>(null)
  const current = useViewer((s) => s.current)
  const focus = useViewer((s) => s.focus)

  useEffect(() => {
    const controls = ref.current
    if (!controls || !current) return
    const box = assetBox(prepareCase(current), focus.assetId)
    if (!box || box.isEmpty()) return
    const pad = box.getSize(new Vector3()).length() * 0.12
    void controls.fitToBox(box, true, { paddingTop: pad, paddingBottom: pad, paddingLeft: pad, paddingRight: pad })
  }, [current, focus])

  useEffect(
    () =>
      gestureBus.on((e) => {
        const controls = ref.current
        if (!controls) return
        if (e.type === 'rotate') void controls.rotate(-e.dx * ROTATE_GAIN, e.dy * ROTATE_GAIN, false)
        if (e.type === 'zoom') void controls.dollyTo(controls.distance / e.scale, false)
      }),
    [],
  )

  return <CameraControls ref={ref} makeDefault minDistance={0.02} maxDistance={1.2} smoothTime={0.25} />
}
```

```tsx
import { useThree } from '@react-three/fiber'
import { useEffect } from 'react'
import { Raycaster, Vector2 } from 'three'
import { gestureBus } from '../gestures/bus'
import { useViewer, viewerStore } from '../state/store'
import { pickTumor } from './picking'
import { prepareCase } from './prepare'

/** Turns gesture pointer events into hover/select through the same picking rules as the mouse. */
export function GesturePicker() {
  const camera = useThree((s) => s.camera)
  const current = useViewer((s) => s.current)

  useEffect(() => {
    if (!current) return
    const prepared = prepareCase(current)
    const raycaster = new Raycaster()
    const ndc = new Vector2()
    return gestureBus.on((e) => {
      const s = viewerStore.getState()
      if (e.type === 'lost') {
        s.hover(null)
        return
      }
      if (e.type !== 'hover' && e.type !== 'select') return
      raycaster.setFromCamera(ndc.set(e.ndc[0], e.ndc[1]), camera)
      const hit = pickTumor(raycaster, prepared)
      if (e.type === 'hover') s.hover(hit?.assetId ?? null)
      else if (hit) s.select(hit.assetId)
    })
  }, [current, camera])

  return null
}
```

```ts
import type { Provenance, TumorAsset, TumorId, Vec3 } from '../lib/manifest'

export const DASH = '—'

export const PROVENANCE_LABEL: Record<Provenance, string> = {
  'ground-truth': 'Ground truth (expert labels)',
  'monai-segresnet': 'Model: MONAI SegResNet',
  synthetic: 'Synthetic test case',
}

/** Medical Segmentation Decathlon Task01 label meanings. No anatomy names. */
export const TUMOR_LABEL: Record<TumorId, string> = {
  tumor_ed: 'Edema (label 1)',
  tumor_ncr: 'Non-enhancing tumor (label 2)',
  tumor_et: 'Enhancing tumor (label 3)',
}

const missing = (v: unknown): v is null | undefined => v === null || v === undefined

export const fmtMl = (v: number | null | undefined) => (missing(v) ? DASH : `${v.toFixed(2)} mL`)
export const fmtMm = (v: number | null | undefined) => (missing(v) ? DASH : `${v.toFixed(1)} mm`)
export const fmtDice = (v: number | null | undefined) => (missing(v) ? DASH : v.toFixed(2))
export const fmtVec = (v: Vec3 | null | undefined) => (missing(v) ? DASH : `(${v.map((x) => x.toFixed(1)).join(', ')})`)

/** Sum of the manifest sub-region volumes; shown labelled as a sum. */
export function totalVolumeMl(tumors: TumorAsset[]): number | null {
  return tumors.length ? tumors.reduce((acc, t) => acc + t.volume_ml, 0) : null
}
```

Create `frontend/src/ui/MriPanel.tsx`:

```tsx
import { type MouseEvent, useEffect, useMemo, useRef } from 'react'
import { type CaseFrame, voxelSpacing } from '../lib/affine'
import { tumorAssets } from '../lib/manifest'
import { markerToSlicePixel, outlineColors, renderSlice, slicePointToRas, sliceRasMm } from '../lib/slice'
import { AXES, type Axis, SLICE_EDGE_LABELS, sliceCount, sliceShape } from '../lib/volume'
import { sliceIndexThrough, useViewer, viewerStore } from '../state/store'
import { TUMOR_LABEL, fmtMm } from './format'

const CANVAS_WIDTH = 512
const RAS_AXIS_NAME: Record<Axis, string> = { axial: 'z', coronal: 'y', sagittal: 'x' }

/** mm per slice pixel along screen columns and rows. */
function pixelSpacing(f: CaseFrame, axis: Axis): { col: number; row: number } {
  const [si, sj, sk] = voxelSpacing(f)
  if (axis === 'axial') return { col: si, row: sj }
  if (axis === 'coronal') return { col: si, row: sk }
  return { col: sj, row: sk }
}

export function MriPanel() {
  const current = useViewer((s) => s.current)
  const slice = useViewer((s) => s.slice)
  const marker = useViewer((s) => s.marker)
  const visible = useViewer((s) => s.visible)
  const canvasRef = useRef<HTMLCanvasElement>(null)

  const image = useMemo(() => {
    if (!current) return null
    const outline = outlineColors(tumorAssets(current.manifest), visible)
    return renderSlice(current.flair, current.mask, slice.axis, slice.index, outline)
  }, [current, slice, visible])

  const canvasHeight = useMemo(() => {
    if (!current) return CANVAS_WIDTH
    const { width, height } = sliceShape(current.frame.dims, slice.axis)
    const sp = pixelSpacing(current.frame, slice.axis)
    return Math.round((CANVAS_WIDTH * height * sp.row) / (width * sp.col))
  }, [current, slice.axis])

  useEffect(() => {
    const canvas = canvasRef.current
    const ctx = canvas?.getContext('2d')
    if (!canvas || !ctx || !image || !current) return
    const off = document.createElement('canvas')
    off.width = image.width
    off.height = image.height
    off.getContext('2d')!.putImageData(new ImageData(image.rgba, image.width, image.height), 0, 0)
    ctx.imageSmoothingEnabled = false
    ctx.clearRect(0, 0, canvas.width, canvas.height)
    ctx.drawImage(off, 0, 0, canvas.width, canvas.height)

    if (!marker) return
    const px = markerToSlicePixel(current.frame, slice.axis, marker)
    const x = ((px.col + 0.5) / image.width) * canvas.width
    const y = ((px.row + 0.5) / image.height) * canvas.height
    const onSlice = Math.round(px.index) === slice.index
    ctx.strokeStyle = '#5BC0CE'
    ctx.globalAlpha = onSlice ? 0.95 : 0.5
    ctx.lineWidth = 2
    ctx.setLineDash(onSlice ? [] : [6, 6])
    ctx.beginPath()
    ctx.moveTo(x, 0)
    ctx.lineTo(x, canvas.height)
    ctx.moveTo(0, y)
    ctx.lineTo(canvas.width, y)
    ctx.stroke()
    ctx.globalAlpha = 1
    ctx.setLineDash([])
  }, [image, marker, current, slice, canvasHeight])

  if (!current || !image) {
    return (
      <section className="panel mri">
        <h2>MRI · FLAIR</h2>
        <p className="muted">No case loaded.</p>
      </section>
    )
  }

  const count = sliceCount(current.frame.dims, slice.axis)
  const edges = SLICE_EDGE_LABELS[slice.axis]
  const s = viewerStore.getState()

  const pickAxis = (axis: Axis) => {
    const index = marker ? sliceIndexThrough(current.frame, axis, marker) : Math.floor(sliceCount(current.frame.dims, axis) / 2)
    s.setSlice(axis, index)
  }

  const onCanvasClick = (e: MouseEvent<HTMLCanvasElement>) => {
    const rect = e.currentTarget.getBoundingClientRect()
    const col = ((e.clientX - rect.left) / rect.width) * image.width - 0.5
    const row = ((e.clientY - rect.top) / rect.height) * image.height - 0.5
    s.setMarker(slicePointToRas(current.frame, slice.axis, slice.index, col, row))
  }

  return (
    <section className="panel mri">
      <div className="panel-head">
        <h2>MRI · FLAIR</h2>
        <div className="tabs" role="tablist">
          {AXES.map((axis) => (
            <button
              key={axis}
              role="tab"
              aria-selected={axis === slice.axis}
              className={axis === slice.axis ? 'tab active' : 'tab'}
              onClick={() => pickAxis(axis)}
            >
              {axis}
            </button>
          ))}
        </div>
      </div>
      <div className="slice-frame">
        <span className="edge edge-left">{edges.left}</span>
        <span className="edge edge-right">{edges.right}</span>
        <span className="edge edge-top">{edges.top}</span>
        <span className="edge edge-bottom">{edges.bottom}</span>
        <canvas
          ref={canvasRef}
          width={CANVAS_WIDTH}
          height={canvasHeight}
          onClick={onCanvasClick}
          aria-label={`${slice.axis} FLAIR slice ${slice.index + 1} of ${count}`}
        />
      </div>
      <label className="slider">
        <input
          type="range"
          min={0}
          max={count - 1}
          value={slice.index}
          onChange={(e) => s.setSlice(slice.axis, Number(e.target.value))}
        />
        <span className="mono">
          {slice.index + 1} / {count} · RAS {RAS_AXIS_NAME[slice.axis]} {fmtMm(sliceRasMm(current.frame, slice.axis, slice.index))}
        </span>
      </label>
      <ul className="legend">
        {tumorAssets(current.manifest).map((t) => (
          <li key={t.id} className={visible[t.id] === false ? 'off' : ''}>
            <i style={{ background: t.color }} /> {TUMOR_LABEL[t.id]}
          </li>
        ))}
      </ul>
    </section>
  )
}
```

```ts
import { rasExtent } from '../lib/affine'
import type { LoadedCase } from '../lib/loadCase'
import { tumorAssets } from '../lib/manifest'
import { RAS_DIM } from '../lib/volume'
import { type CutPlane, DEFAULT_OPACITY, type ToolSource, type ViewerState, type ViewerStore, viewerStore } from '../state/store'
import { type ToolResult, executeTool, newCallId } from '../tools/execute'

export interface ToolRequest {
  name: string
  args: unknown
}

type Plane = Exclude<CutPlane, 'none'>

/** RAS mm range of the volume along the plane's axis; set_cutaway clamps to the same range. */
export function cutawayRange(c: LoadedCase, plane: Plane): { min: number; max: number } {
  const e = rasExtent(c.frame)
  const d = RAS_DIM[plane]
  return { min: e.min[d], max: e.max[d] }
}

/** Where a newly chosen cutaway starts: through the first tumour centroid, else mid-volume. */
export function defaultCutMm(c: LoadedCase, plane: Plane): number {
  const first = tumorAssets(c.manifest)[0]
  if (first) return first.centroid_ras[RAS_DIM[plane]]
  const { min, max } = cutawayRange(c, plane)
  return (min + max) / 2
}

/** The tool calls that put the scene back to the case's initial view. */
export function resetViewCalls(c: LoadedCase): ToolRequest[] {
  const ids = c.manifest.assets.map((a) => a.id)
  return [
    { name: 'set_cutaway', args: { plane: 'none' } },
    { name: 'hide_hemisphere', args: { side: 'none' } },
    { name: 'toggle_visibility', args: { asset_ids: ids, visible: true } },
    ...ids.map((id) => ({ name: 'set_opacity', args: { asset_id: id, value: DEFAULT_OPACITY[id] ?? 1 } })),
    { name: 'focus_region', args: { asset_id: 'brain_surface' } },
  ]
}

export async function runTools(store: ViewerStore, requests: ToolRequest[], source: ToolSource): Promise<ToolResult[]> {
  const results: ToolResult[] = []
  for (const r of requests) results.push(await executeTool(store, { id: newCallId(source), ...r }, source))
  return results
}

export const runUi = async (name: string, args: unknown): Promise<ToolResult> =>
  (await runTools(viewerStore, [{ name, args }], 'ui'))[0]

/** Header chip text. Spec §7: a denied or missing webcam falls back to mouse and keyboard, visibly. */
export function webcamLabel(
  webcam: ViewerState['webcam'],
  gesturesOn: boolean,
): { text: string; tone: 'ok' | 'bad' | 'idle' } {
  const fallback = 'mouse and keyboard'
  if (!gesturesOn) return { text: `Gestures off · ${fallback}`, tone: 'idle' }
  switch (webcam.status) {
    case 'on':
      return { text: `Hand tracking · ${webcam.hands} ${webcam.hands === 1 ? 'hand' : 'hands'}`, tone: 'ok' }
    case 'denied':
      return { text: `Webcam denied · ${fallback}`, tone: 'bad' }
    case 'unavailable':
      return { text: `Webcam unavailable${webcam.error ? ` (${webcam.error})` : ''} · ${fallback}`, tone: 'bad' }
    default:
      return { text: 'Webcam starting…', tone: 'idle' }
  }
}
```

### Task 10: Keyboard shortcuts for every tool

Spec §6: every tool has a keyboard shortcut as the demo fallback. The mapping is a pure function from (key, state) to a tool request, so the tests can drive it against the real store. The window listener is a thin hook that ignores keys typed into form fields.

|---|---|
| `1` `2` `3` | `inspect_mri_slice` axial / coronal / sagittal, through the marker |

```ts
import { tumorAssets } from '../lib/manifest'
import { type Axis, sliceCount } from '../lib/volume'
import { type Viewer, sliceIndexThrough } from '../state/store'
import { type ToolRequest, defaultCutMm } from '../ui/controls'
import { CUT_PLANES, HEMISPHERES } from './schemas'

export interface Shortcut {
  keys: string[]
  label: string
  /** The tool the key calls; null for app toggles. */
  tool: string | null
}

export const SHORTCUTS: Shortcut[] = [
  { keys: ['1', '2', '3'], label: 'Axial / coronal / sagittal slice at marker', tool: 'inspect_mri_slice' },
  { keys: ['↑', '↓'], label: 'Next / previous slice', tool: 'inspect_mri_slice' },
  { keys: ['[', ']'], label: 'Brain opacity −/+', tool: 'set_opacity' },
  { keys: ['C'], label: 'Cycle cutaway plane', tool: 'set_cutaway' },
  { keys: ['H'], label: 'Cycle hidden hemisphere', tool: 'hide_hemisphere' },
  { keys: ['F'], label: 'Focus selection', tool: 'focus_region' },
  { keys: ['B'], label: 'Show / hide brain', tool: 'toggle_visibility' },
  { keys: ['T'], label: 'Show / hide tumour', tool: 'toggle_visibility' },
  { keys: ['N'], label: 'Next case', tool: 'load_case' },
  { keys: ['G'], label: 'Gesture mode on / off', tool: null },
]

const AXIS_KEYS: Record<string, Axis> = { '1': 'axial', '2': 'coronal', '3': 'sagittal' }
const OPACITY_STEP = 0.1

export const normalizeKey = (key: string) => (key.length === 1 ? key.toLowerCase() : key)

const next = <T>(list: readonly T[], value: T): T => list[(list.indexOf(value) + 1) % list.length]

export function shortcutToCall(rawKey: string, s: Viewer): ToolRequest | null {
  const key = normalizeKey(rawKey)

  if (key === 'n') {
    const cases = s.index?.cases ?? []
    if (cases.length < 2) return null
    const at = cases.findIndex(
      (c) => c.case_id === s.current?.manifest.case_id && c.provenance === s.current?.manifest.provenance,
    )
    const target = cases[(at + 1) % cases.length]
    return { name: 'load_case', args: { case_id: target.case_id, provenance: target.provenance } }
  }

  const c = s.current
  if (!c) return null
  const tumorIds = tumorAssets(c.manifest).map((t) => t.id)

  if (key in AXIS_KEYS) {
    const axis = AXIS_KEYS[key]
    const index = s.marker ? sliceIndexThrough(c.frame, axis, s.marker) : Math.floor(sliceCount(c.frame.dims, axis) / 2)
    return { name: 'inspect_mri_slice', args: { axis, index } }
  }

  switch (key) {
    case 'ArrowUp':
    case 'ArrowDown':
      return {
        name: 'inspect_mri_slice',
        args: { axis: s.slice.axis, index: s.slice.index + (key === 'ArrowUp' ? 1 : -1) },
      }
    case '[':
    case ']': {
      const now = s.opacity.brain_surface ?? 0.45
      const value = Math.round((now + (key === ']' ? OPACITY_STEP : -OPACITY_STEP)) * 100) / 100
      return { name: 'set_opacity', args: { asset_id: 'brain_surface', value } }
    }
    case 'c': {
      const plane = next(CUT_PLANES, s.cutaway.plane)
      return { name: 'set_cutaway', args: plane === 'none' ? { plane } : { plane, ras_mm: defaultCutMm(c, plane) } }
    }
    case 'h':
      return { name: 'hide_hemisphere', args: { side: next(HEMISPHERES, s.hemisphere) } }
    case 'f': {
      const target = s.selected ?? tumorIds[0] ?? 'brain_surface'
      return { name: 'focus_region', args: { asset_id: target } }
    }
    case 'b':
      return {
        name: 'toggle_visibility',
        args: { asset_ids: ['brain_surface'], visible: s.visible.brain_surface === false },
      }
    case 't':
      if (!tumorIds.length) return null
      return {
        name: 'toggle_visibility',
        args: { asset_ids: tumorIds, visible: !tumorIds.every((id) => s.visible[id] !== false) },
      }
    default:
      return null
  }
}
```

The hemisphere cycle relies on `HEMISPHERES` being `['left', 'right', 'none']`: `next` from `'none'` wraps to `'left'`. The cutaway cycle relies on `CUT_PLANES` being `['axial', 'coronal', 'sagittal', 'none']` in the same way.

```ts
import { useEffect } from 'react'
import { viewerStore } from '../state/store'
import { runTools } from '../ui/controls'
import { normalizeKey, shortcutToCall } from './shortcuts'

const isTyping = (t: EventTarget | null) =>
  t instanceof HTMLElement && (t.isContentEditable || ['INPUT', 'SELECT', 'TEXTAREA'].includes(t.tagName))

export function useShortcuts(): void {
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (e.metaKey || e.ctrlKey || e.altKey || e.repeat || isTyping(e.target)) return
      const s = viewerStore.getState()
      if (normalizeKey(e.key) === 'g') {
        s.setGesturesOn(!s.gesturesOn)
        return
      }
      const req = shortcutToCall(e.key, s)
      if (!req) return
      e.preventDefault()
      void runTools(viewerStore, [req], 'keyboard')
    }
    window.addEventListener('keydown', onKey)
    return () => window.removeEventListener('keydown', onKey)
  }, [])
}
```

`e.repeat` is ignored so a held key does not queue dozens of calls; tap the arrow keys to step slices.

### Task 11: Gesture reducer

The per-frame gesture logic is a pure function `stepGesture(state, hands) → { state, events }`. Task 12's hook keeps `state` in a `useRef` (spec §6 fix 1) and forwards `events` to `gestureBus`. Selection fires only on the pinch rising edge (fix 2). Picking goes through `pickTumor`, which never hits `brain_surface` (fix 3, Task 6). Materials are per asset (fix 4, Task 6).

Definitions (MediaPipe hand landmark indices: 0 wrist, 4 thumb tip, 8 index tip, 9 middle-finger MCP):
- Palm size: distance wrist → middle MCP. The pinch measure is `ratio = |thumb tip − index tip| / palm size`, so it does not depend on how far the hand is from the camera.
- Pinch hysteresis: the pinch turns on when the smoothed ratio falls below `pinchOn` (0.3) and turns off only when it rises above `pinchOff` (0.45).
- Pointer: the midpoint of the thumb and index tips, which stays put while the fingers close. Palm centre: the midpoint of wrist and middle MCP.
- Coordinates: MediaPipe gives image coordinates (x right, y down, 0..1, camera not mirrored). They are mirrored to NDC with `ndcX = 1 − 2x`, `ndcY = 1 − 2y`, so moving the hand right moves the pointer right, as in a mirror.
- Smoothing: an EMA with `alpha` 0.5 on the ratio, pointer, palm centre and two-hand spread.
- One hand, not pinched: emit `hover` at the pointer every frame, and `rotate` with the palm-centre delta when it exceeds `rotateDeadzone`. One hand, pinched: emit nothing (no rotation while selecting).
- Two hands: emit `zoom` with `scale = spread / previous spread` (palm-centre distance) when `|scale − 1|` exceeds `zoomDeadzone`.
- Leaving one-hand mode emits `lost`, which clears the hover.

```ts
import type { Landmark } from '../gestures/pinch'

/**
 * 21 synthetic MediaPipe hand landmarks in image coordinates (x right, y down, 0..1).
 * Only the landmarks the reducer reads are placed; the rest sit at the palm centre.
 */
export function makeHand({ x = 0.5, y = 0.5, palm = 0.2, pinch = 1 }: { x?: number; y?: number; palm?: number; pinch?: number } = {}): Landmark[] {
  const at = (px: number, py: number): Landmark => ({ x: px, y: py, z: 0 })
  const hand = Array.from({ length: 21 }, () => at(x, y))
  const gap = pinch * palm
  const tipY = y - 0.9 * palm
  hand[0] = at(x, y + palm / 2) // wrist
  hand[9] = at(x, y - palm / 2) // middle-finger MCP
  hand[4] = at(x - gap / 2, tipY) // thumb tip
  hand[8] = at(x + gap / 2, tipY) // index tip
  return hand
}
```

```ts
import type { GestureEvent, NdcPoint } from './bus'

export interface Landmark {
  x: number
  y: number
  z: number
}

const WRIST = 0
const THUMB_TIP = 4
const INDEX_TIP = 8
const MIDDLE_MCP = 9

export const GESTURE_CONFIG = {
  /** Pinch turns on below this thumb–index / palm-size ratio... */
  pinchOn: 0.3,
  /** ...and off only above this one, so jitter between the two cannot flicker. */
  pinchOff: 0.45,
  /** EMA weight of the newest sample. */
  alpha: 0.5,
  /** Palm-centre motion per frame, in NDC, below which an open hand does not rotate. */
  rotateDeadzone: 0.002,
  /** |scale - 1| per frame below which two hands do not zoom. */
  zoomDeadzone: 0.003,
}
export type GestureConfig = typeof GESTURE_CONFIG

export interface GestureState {
  hands: number
  pinched: boolean
  ratio: number | null
  pointer: NdcPoint | null
  palm: NdcPoint | null
  spread: number | null
}

export const initialGestureState = (): GestureState => ({
  hands: 0,
  pinched: false,
  ratio: null,
  pointer: null,
  palm: null,
  spread: null,
})

const dist = (a: Landmark, b: Landmark) => Math.hypot(a.x - b.x, a.y - b.y)
const ema = (prev: number | null, next: number, alpha: number) => (prev === null ? next : prev + alpha * (next - prev))
const emaPoint = (prev: NdcPoint | null, next: NdcPoint, alpha: number): NdcPoint =>
  prev === null ? next : [ema(prev[0], next[0], alpha), ema(prev[1], next[1], alpha)]
/** Mirrored: the user sees themselves as in a mirror. */
const toNdc = (a: Landmark, b: Landmark): NdcPoint => [1 - (a.x + b.x), 1 - (a.y + b.y)]

export function stepGesture(
  prev: GestureState,
  hands: Landmark[][],
  cfg: GestureConfig = GESTURE_CONFIG,
): { state: GestureState; events: GestureEvent[] } {
  const events: GestureEvent[] = []
  const n = hands.length
  if (n !== 1 && prev.hands === 1) events.push({ type: 'lost' })
  if (n === 0) return { state: initialGestureState(), events }

  if (n >= 2) {
    const [a, b] = hands.map((h) => toNdc(h[WRIST], h[MIDDLE_MCP]))
    const spread = ema(prev.spread, Math.hypot(a[0] - b[0], a[1] - b[1]), cfg.alpha)
    if (prev.spread !== null && prev.spread > 0) {
      const scale = spread / prev.spread
      if (Math.abs(scale - 1) > cfg.zoomDeadzone) events.push({ type: 'zoom', scale })
    }
    return { state: { ...initialGestureState(), hands: n, spread }, events }
  }

  const h = hands[0]
  const size = dist(h[WRIST], h[MIDDLE_MCP])
  const ratio = ema(prev.ratio, size > 0 ? dist(h[THUMB_TIP], h[INDEX_TIP]) / size : Infinity, cfg.alpha)
  const pointer = emaPoint(prev.pointer, toNdc(h[THUMB_TIP], h[INDEX_TIP]), cfg.alpha)
  const palm = emaPoint(prev.palm, toNdc(h[WRIST], h[MIDDLE_MCP]), cfg.alpha)

  let pinched = prev.pinched
  if (!pinched && ratio < cfg.pinchOn) {
    pinched = true
    events.push({ type: 'select', ndc: pointer })
  } else if (pinched && ratio > cfg.pinchOff) {
    pinched = false
  }

  if (!pinched) {
    events.push({ type: 'hover', ndc: pointer })
    if (prev.hands === 1 && prev.palm) {
      const dx = palm[0] - prev.palm[0]
      const dy = palm[1] - prev.palm[1]
      if (Math.hypot(dx, dy) > cfg.rotateDeadzone) events.push({ type: 'rotate', dx, dy })
    }
  }

  return { state: { hands: 1, pinched, ratio, pointer, palm, spread: null }, events }
}
```

`toNdc(a, b)` is the mirrored NDC of the midpoint of `a` and `b`: `1 − 2·(a.x + b.x)/2 = 1 − (a.x + b.x)`.

```ts
import { FilesetResolver, HandLandmarker } from '@mediapipe/tasks-vision'
import { useEffect, useRef } from 'react'
import { useViewer, viewerStore } from '../state/store'
import { gestureBus } from './bus'
import { type GestureState, initialGestureState, stepGesture } from './pinch'

export const MEDIAPIPE_WASM = '/mediapipe/wasm'
export const HAND_MODEL = '/mediapipe/hand_landmarker.task'

const messageOf = (e: unknown) => (e instanceof Error ? e.message : String(e))

/** Webcam + MediaPipe loop, active only while gesture mode is on. */
export function useHandTracking(): void {
  const gesturesOn = useViewer((s) => s.gesturesOn)
  // Spec §6 fix 1: per-frame gesture state lives in a ref, never in React state.
  const gesture = useRef<GestureState>(initialGestureState())

  useEffect(() => {
    const { setWebcam } = viewerStore.getState()
    if (!gesturesOn) {
      setWebcam({ status: 'off', hands: 0, error: null })
      return
    }

    let cancelled = false
    let stream: MediaStream | null = null
    let landmarker: HandLandmarker | null = null
    let raf = 0
    const video = document.createElement('video')
    video.muted = true
    video.playsInline = true

    const stop = () => {
      cancelAnimationFrame(raf)
      stream?.getTracks().forEach((t) => t.stop())
      landmarker?.close()
      video.srcObject = null
      gesture.current = initialGestureState()
      gestureBus.emit({ type: 'lost' })
    }

    async function start() {
      setWebcam({ status: 'starting', hands: 0, error: null })
      if (!navigator.mediaDevices?.getUserMedia) {
        setWebcam({ status: 'unavailable', error: 'this browser has no camera API' })
        return
      }
      try {
        stream = await navigator.mediaDevices.getUserMedia({
          video: { width: 640, height: 480, facingMode: 'user' },
          audio: false,
        })
      } catch (e) {
        const denied = e instanceof DOMException && (e.name === 'NotAllowedError' || e.name === 'SecurityError')
        if (!cancelled) setWebcam({ status: denied ? 'denied' : 'unavailable', error: denied ? null : messageOf(e) })
        return
      }
      if (cancelled) return stop()
      try {
        video.srcObject = stream
        await video.play()
        const fileset = await FilesetResolver.forVisionTasks(MEDIAPIPE_WASM)
        landmarker = await HandLandmarker.createFromOptions(fileset, {
          baseOptions: { modelAssetPath: HAND_MODEL, delegate: 'GPU' },
          runningMode: 'VIDEO',
          numHands: 2,
        })
      } catch (e) {
        if (!cancelled) setWebcam({ status: 'unavailable', error: `hand tracking failed to start: ${messageOf(e)}` })
        return stop()
      }
      if (cancelled) return stop()
      setWebcam({ status: 'on', hands: 0, error: null })

      let lastVideoTime = -1
      const tick = () => {
        if (cancelled || !landmarker) return
        if (video.currentTime !== lastVideoTime) {
          lastVideoTime = video.currentTime
          const result = landmarker.detectForVideo(video, performance.now())
          const { state, events } = stepGesture(gesture.current, result.landmarks)
          const handsChanged = state.hands !== gesture.current.hands
          gesture.current = state
          for (const e of events) gestureBus.emit(e)
          if (handsChanged) setWebcam({ hands: state.hands })
        }
        raf = requestAnimationFrame(tick)
      }
      raf = requestAnimationFrame(tick)
    }

    void start()
    return () => {
      cancelled = true
      stop()
    }
  }, [gesturesOn])
}
```

`stop` can run twice (once from an aborted `start` and once from cleanup). Every step in it is safe to repeat. Under React StrictMode the effect mounts, cleans up and mounts again; the first `start` sees `cancelled` after its next `await` and releases what it opened.

```tsx
import { useEffect, useRef } from 'react'
import { gestureBus } from './bus'

/** Reticle at the hand pointer. Moved by bus events straight on the DOM node, never through React state. */
export function GestureCursor() {
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    let pulse = 0
    const off = gestureBus.on((e) => {
      const el = ref.current
      if (!el) return
      if (e.type === 'lost') {
        el.style.opacity = '0'
        return
      }
      if (e.type !== 'hover' && e.type !== 'select') return
      el.style.opacity = '1'
      el.style.left = `${((e.ndc[0] + 1) / 2) * 100}%`
      el.style.top = `${((1 - e.ndc[1]) / 2) * 100}%`
      if (e.type === 'select') {
        el.classList.add('pinch')
        window.clearTimeout(pulse)
        pulse = window.setTimeout(() => el.classList.remove('pinch'), 250)
      }
    })
    return () => {
      off()
      window.clearTimeout(pulse)
    }
  }, [])

  return <div ref={ref} className="gesture-cursor" aria-hidden="true" />
}
```

````markdown
Browser viewer for baked cases (`public/cases/<case_id>/<provenance>/`). It shows the patient's brain surface and tumour sub-regions in 3D, linked to a 2D MRI slice panel, and drives everything through one tool executor that the keyboard, webcam gestures and (later) the agent all call.

## Controls

| Input | Action |
|---|---|
| Mouse drag / scroll | rotate / zoom |
| Click a tumour sub-region | select it; the MRI crosshair moves to its centroid |
| Click the MRI slice | place the marker there |
| `1` `2` `3` | axial / coronal / sagittal slice through the marker |
| `↑` `↓` | next / previous slice |
| `[` `]` | brain surface opacity −0.1 / +0.1 |
| `c` | cutaway: off → axial → coronal → sagittal → off |
| `h` | hide hemisphere: none → left → right → none |
| `f` | focus the selected sub-region |
| `b` / `t` | toggle brain surface / all tumour sub-regions |
| `n` | next case in the index |
| `g` | webcam gesture mode on/off |

Gesture mode: an open hand rotates, a pinch selects what is under the reticle, and two hands moving apart or together zoom. If the camera is denied or missing, the header says so and mouse and keyboard keep working.

## Layout of `src/`

- `lib/`: pure, tested code. The manifest schema, affine math (`vox2ras`, its inverse, `ras2gl`), volume slicing, slice rendering and case loading.
- `state/store.ts`: the single zustand store with all view state.
- `tools/`: zod tool schemas, `executeTool`, and the keyboard shortcut mapping.
- `scene/`: three / react-three-fiber. Per-asset materials, clipping planes, picking (never the brain surface) and camera.
- `gestures/`: the event bus, the pure pinch reducer (`pinch.ts`) and the webcam hook.
- `ui/`: panels and formatting. Every number shown comes from `manifest.json`. Missing values render as `—`.

## Agent hook

`executeTool(store, { id, name, args }, source)` in `src/tools/execute.ts` is the only way the scene changes on request. It validates `args` with zod, rejects unknown asset ids and keys, clamps numeric ranges, logs the call in the Agent console and returns `{ id, ok: true, result }` or `{ id, ok: false, error }`. The Plan C WebSocket client calls it. Dev builds expose it in the console:

```js
await __jarvis.executeTool(__jarvis.store, { id: 'x', name: 'focus_region', args: { asset_id: 'tumor_et' } })
```

Tools: `load_case`, `set_opacity`, `focus_region`, `set_cutaway`, `hide_hemisphere`, `toggle_visibility`, `inspect_mri_slice`.

- The 2D slice orientation (radiological: patient right on screen left) is verified on the synthetic case only. Re-check it on a real MSD case (spec §9). It is set in one place: `slicePixelToVoxel` / `voxelToSlicePixel` in `src/lib/volume.ts`.
- The opacity and cutaway sliders write the store directly and do not appear in the Agent console. Their keyboard and agent equivalents do.
````
