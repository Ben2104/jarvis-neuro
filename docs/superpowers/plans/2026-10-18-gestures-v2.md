# Gestures v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the webcam gesture mapping with: point = hover, pinch on the brain + drag = rotate, pinch-tap = select, open hand = explode by how far the hand is open, fist = close, two hands = zoom; draw the 21 hand landmarks over the webcam; let hover/select work on any pickable part, also while exploded.

**Architecture:** The pure reducer `stepGesture` (in `src/gestures/pinch.ts`) classifies one hand per frame into a pose and emits bus events. A new scene component `GestureController` (replaces `GesturePicker`) turns them into hover, select, rotate and explode. A new DOM overlay `HandOverlay` draws landmarks from a new `landmarks` bus event. Picking goes through `PreparedCase.pickMeshes`, so the atlas work on another branch can add brain-region meshes without touching gesture code.

**Tech Stack:** React 19, three 0.186, @react-three/fiber 9, @react-three/drei CameraControls, MediaPipe tasks-vision HandLandmarker, zustand 5, vitest 5.

## Global Constraints

- Per-frame gesture state never goes through React state (spec §6 fix 1). Bus events and DOM/canvas writes only.
- Gesture rotate/explode/zoom write the store or camera directly, like today; they do not go through `executeTool` (they are per-frame).
- The brain_surface halves keep `raycast = () => {}`: rays pass through the brain to what is inside. "Pinch on the brain" is a bounding-box test, not a mesh raycast.
- Mouse and keyboard behaviour must not change.
- Do not touch `src/scene/materials.ts`, `src/scene/viewState.ts`, `backend/`, or the bake pipeline: another branch (atlas + look) changes those.
- Every number in the config below is a starting value that needs tuning with a real hand; keep them all in `GESTURE_CONFIG`.

## Interfaces shared with the atlas/look branch

- `PreparedCase.pickMeshes: Mesh[]` — every mesh hover/select may hit. This plan sets it to the tumour meshes. The atlas branch appends brain-region meshes. Each mesh carries `userData.assetId`.
- `pickPart(raycaster, prepared): PickHit | null` in `src/scene/picking.ts` replaces `pickTumor`, same rules (nearest visible hit not clipped away), over `pickMeshes`.

### Task 1: Pose-aware reducer

**Files:** `src/gestures/bus.ts`, `src/gestures/pinch.ts`, `src/test/hands.ts`, `src/gestures/pinch.test.ts`

**Produces:**

```ts
// bus.ts
export type HandPose = 'open' | 'point' | 'fist' | 'pinch' | 'other'
export type GestureEvent =
  | { type: 'hover'; ndc: NdcPoint; pose: HandPose }
  | { type: 'pinchStart'; ndc: NdcPoint }
  | { type: 'drag'; dx: number; dy: number }
  | { type: 'pinchEnd'; ndc: NdcPoint; tap: boolean }
  | { type: 'explode'; amount: number }        // absolute, 0..1
  | { type: 'zoom'; scale: number }
  | { type: 'landmarks'; hands: NdcPoint[][] } // mirrored NDC over the camera frame, 21 per hand
  | { type: 'lost' }
// pinch.ts
export function stepGesture(prev: GestureState, hands: Landmark[][], now: number, cfg?: GestureConfig): { state: GestureState; events: GestureEvent[] }
export function classifyPose(h: Landmark[], pinched: boolean): HandPose
export function openness(h: Landmark[]): number // mean distance of the 5 fingertips from the palm centre / palm size
```

Landmark indices (MediaPipe): wrist 0; thumb tip 4; index PIP 6, tip 8; middle MCP 9, PIP 10, tip 12; ring PIP 14, tip 16; pinky PIP 18, tip 20; index MCP 5; pinky MCP 17.

Rules:

- Palm size = `dist(wrist, middleMCP)`. Palm centre = mean of wrist, index MCP, pinky MCP.
- A finger (index, middle, ring, pinky) is extended when `dist(wrist, tip) > cfg.extendRatio * dist(wrist, pip)` (`extendRatio = 1.15`).
- `classifyPose`: `'pinch'` if pinched; else `'open'` if 4 fingers extended; `'point'` if index extended and middle, ring, pinky not; `'fist'` if none extended; else `'other'`.
- Pinch hysteresis and arming stay exactly as today (`pinchOn 0.3`, `pinchOff 0.45`, armed by a ratio above `pinchOff`).
- Pointer = mirrored index tip (landmark 8), EMA-smoothed with `alpha`. One hand: emit `hover {ndc: pointer, pose}` every frame, in every pose.
- Pinch turns on → `pinchStart {ndc}`; record `pinchAt = now`, `pinchFrom = pointer`, `travel = 0`.
- While pinched and previously pinched: `drag {dx, dy}` from the pointer delta when `hypot(dx, dy) > dragDeadzone (0.002)`; add the delta length to `travel`.
- Pinch turns off → `pinchEnd {ndc, tap}` where `tap = now - pinchAt <= tapMaxMs (300) && travel <= tapMaxTravel (0.03)`.
- Explode: when the pose is `'open'` for `poseFrames (3)` consecutive frames, `amount = clamp01((openness - openMin) / (openMax - openMin))` with `openMin = 1.1`, `openMax = 1.9`; emit `explode {amount}` when `|amount - lastExplode| > explodeDeadzone (0.01)` or on the first open frame. When the pose is `'fist'` for `poseFrames` frames, emit `explode {amount: 0}` once. `'point'`, `'pinch'`, `'other'` emit no explode (the amount holds, so exploded parts stay put for hovering).
- Two hands: `zoom` exactly as today; no hover, no explode. Hands going from 1 to anything else: `lost` as today; a pinch in progress ends without `pinchEnd`.
- Removed: `select`, `rotate`, `explode {delta}` and their config keys (`rotateDeadzone`, `explodeGain`).

### Task 4: GestureController

**Files:** create `src/scene/grab.ts`, `src/scene/grab.test.ts`, `src/scene/GestureController.tsx`; delete `src/scene/GesturePicker.tsx`; modify `src/scene/CameraRig.tsx`, `src/scene/Viewer.tsx`, `src/gestures/GestureCursor.tsx`, `src/ui/layout.css`

**Produces:**

```ts
// grab.ts — pure
export interface GrabState { grabbing: boolean }
export function onPinchStart(onBrain: boolean): GrabState            // grabbing = onBrain
export function dragToRotate(g: GrabState, dx: number, dy: number): [number, number] | null // [-dx*π, dy*π] or null
```

Behaviour of `GestureController` (inside the r3f Canvas, one bus listener, `useThree` for camera, size and `controls`):

- `hover`: raycast `pickPart` from `viewNdc(ndc)`; `store.hover(hit?.assetId ?? null)`.
- `pinchStart`: compute the world `Box3` of `prepared.root` (only visible meshes, after `updateMatrixWorld`); `onBrain = raycaster.ray.intersectsBox(box)`; keep the GrabState in a ref.
- `drag`: `const r = dragToRotate(grab, dx, dy); if (r) controls.rotate(r[0], r[1], false)`.
- `pinchEnd`: if `tap`, pick at `ndc` and `store.select(hit.assetId)` when hit (a tap on nothing does nothing); then `grabbing = false`.
- `explode`: `store.setExplode(amount)` (store clamps).
- `lost`: `store.hover(null)`, `grabbing = false`.
- `CameraRig` keeps its `zoom` listener and focus effect; remove its `rotate` and `explode` listeners (`ROTATE_GAIN` moves to `grab.ts`).
- `GestureCursor`: listen to `hover` (all poses) and `pinchStart`/`pinchEnd`; set `data-pose` on the node to the hover pose, add class `grab` between a `pinchStart` that is on the brain and `pinchEnd` (the controller can't reach the cursor, so the cursor shows `pinch` on every pinch and that is enough: keep the existing `pinch` class while pinched). CSS: `.gesture-cursor[data-pose="open"]` larger ring, `[data-pose="point"]` small dot, `[data-pose="fist"]` filled.
