# Agent Backend + Voice (Plan C) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user drive the viewer by voice or text: a Strands Orchestrator in FastAPI turns requests into the existing browser tool calls, and a Clinical Reasoner answers questions from manifest facts only.

**Architecture:** One WebSocket (`/ws`) joins the browser and FastAPI. Per connection, the server builds an Orchestrator agent whose tools validate and clamp their arguments in Python, forward the scene call to the browser over the socket, and await `{ok, result|error}` from the existing `executeTool`. `explain` runs a separate Reasoner agent over the manifest facts of the loaded case. The browser adds a reconnecting socket client, Web Speech input/output and a transcript in the Agent console. Mouse, keyboard and gestures keep working when the agent is down.

**Tech Stack:** Python 3.12, uv, FastAPI 0.143 + uvicorn 0.54, Strands Agents 1.61 (`strands-agents[anthropic,gemini]`), pydantic 2, pytest + httpx (TestClient). Frontend: Vite 8, React 19, TypeScript 6, zustand 5, zod 4, vitest 5, Web Speech API.

## Decisions needed (user, before Task 10)

1. **Gemini model ids.** The spec gives defaults only for Anthropic. With `MODEL_PROVIDER=gemini`, `ORCHESTRATOR_MODEL` and `REASONER_MODEL` are required and the server reports the missing one. This plan does not invent Gemini ids.
2. **Demo provider.** The spec says it "is decided before rehearsal, and every rehearsal runs on that provider". Task 10 runs on whichever provider is chosen.
3. **Atlas answer: prompt-only or a hard guard.** This plan puts the scripted sentence (`ATLAS_ANSWER`) in the Reasoner prompt and tests that it is there. A keyword guard in code would be deterministic but brittle (it cannot tell "how far from the surface" from "how far from the motor strip" reliably). If judges must never see a model-worded variant, add the guard after Task 10 shows how the model behaves.

## Spec tension (flagged, not resolved)

Decision 5 says LLMs never produce coordinates. Two §5 tools take a number the LLM must pick: `set_cutaway(ras_mm)` and `inspect_mri_slice(index)`. This plan keeps the spec's tool signatures and limits the damage: the Orchestrator prompt says `ras_mm` must be copied from a `centroid_ras` / `bbox_ras` value a tool returned, and to prefer `focus_region` (which moves the slice to the centroid) over guessing a slice index; the backend clamps both into the volume. A stricter fix (replace `ras_mm` with `through: asset_id`) changes the spec and the Plan B tool schema, so it is left to the user.

## Message protocol (`/ws`, JSON text frames)

| Direction | Message | Meaning |
|---|---|---|
| server → browser | `{type:"status", state:"ready"\|"unavailable", detail}` | Sent once per connection. `detail` is the config problem, or `null`. |
| server → browser | `{type:"busy", busy}` | A user turn started / ended. |
| server → browser | `{type:"tool_call", id, name, args}` | Run this scene tool; reply with `tool_result` carrying the same `id`. |
| server → browser | `{type:"reply", turn_id, text}` | The Orchestrator's answer to a user turn. |
| server → browser | `{type:"error", turn_id\|null, message}` | A turn failed, or a client message was rejected. |
| browser → server | `{type:"user", turn_id, text}` | One user turn (1–2000 chars). |
| browser → server | `{type:"tool_result", id, ok, result\|error}` | The `executeTool` result. |
| browser → server | `{type:"case", case_id, provenance}` | The case the browser shows (on open and on every case change). |

```python
"""Model provider selection from environment variables (spec §1 Stack). No provider is hard-coded."""
import os
from collections.abc import Mapping
from dataclasses import dataclass

from strands.models.model import Model

PROVIDERS = ("gemini", "anthropic")
# Spec §5 defaults, Anthropic provider only.
ANTHROPIC_DEFAULTS = {"ORCHESTRATOR_MODEL": "claude-haiku-5-5", "REASONER_MODEL": "claude-sonnet-5-5"}
KEY_VAR = {"gemini": "GEMINI_API_KEY", "anthropic": "ANTHROPIC_API_KEY"}
MAX_TOKENS = 1024


class ConfigError(ValueError):
    """The environment does not describe a usable model provider."""


@dataclass(frozen=True)
class AgentSettings:
    provider: str
    orchestrator_model: str
    reasoner_model: str
    api_key: str


def load_settings(env: Mapping[str, str] | None = None) -> AgentSettings:
    env = os.environ if env is None else env
    provider = env.get("MODEL_PROVIDER", "").strip().lower()
    if provider not in PROVIDERS:
        raise ConfigError(f"MODEL_PROVIDER must be one of {', '.join(PROVIDERS)}; got {provider!r}")
    key = env.get(KEY_VAR[provider], "").strip()
    if not key:
        raise ConfigError(f"{KEY_VAR[provider]} is not set")

    def model_id(var: str) -> str:
        value = env.get(var, "").strip()
        if value:
            return value
        if provider == "anthropic":
            return ANTHROPIC_DEFAULTS[var]
        raise ConfigError(f"{var} is required when MODEL_PROVIDER={provider}")

    return AgentSettings(provider, model_id("ORCHESTRATOR_MODEL"), model_id("REASONER_MODEL"), key)


def build_model(settings: AgentSettings, model_id: str) -> Model:
    """A Strands model for one role. Constructing it makes no network call."""
    if settings.provider == "anthropic":
        from strands.models.anthropic import AnthropicModel

        return AnthropicModel(client_args={"api_key": settings.api_key}, model_id=model_id, max_tokens=MAX_TOKENS)
    from strands.models.gemini import GeminiModel

    return GeminiModel(client_args={"api_key": settings.api_key}, model_id=model_id)
```

```python
"""Read the baked case index and manifests from disk (spec decision 5: every number comes from manifest.json)."""
import os
from pathlib import Path
from typing import Any

from ..manifest import CaseIndex, IndexEntry, Manifest, TumorAsset

REPO_ROOT = Path(__file__).resolve().parents[4]
DEFAULT_CASES_DIR = REPO_ROOT / "frontend" / "public" / "cases"


def cases_dir() -> Path:
    return Path(os.environ.get("CASES_DIR", DEFAULT_CASES_DIR))


def hemisphere_of(x: float, midline_x: float) -> str:
    """RAS +x is patient right. Same rule as the viewer's hemisphereOf."""
    if x < midline_x:
        return "left"
    if x > midline_x:
        return "right"
    return "midline"


class CaseRepo:
    def __init__(self, root: Path | None = None):
        self.root = Path(root) if root is not None else cases_dir()

    def index(self) -> CaseIndex:
        return CaseIndex.model_validate_json((self.root / "index.json").read_text())

    def entry(self, case_id: str, provenance: str | None = None) -> IndexEntry:
        """The index entry the viewer would load: the first match in index order."""
        cases = self.index().cases
        same_id = [e for e in cases if e.case_id == case_id]
        if not same_id:
            known = sorted({e.case_id for e in cases})
            raise ValueError(f"unknown case_id {case_id!r}; expected one of {', '.join(known)}")
        match = [e for e in same_id if provenance is None or e.provenance == provenance]
        if not match:
            available = ", ".join(e.provenance for e in same_id)
            raise ValueError(f"no case {case_id} with provenance {provenance}; available: {available}")
        return match[0]

    def manifest(self, entry: IndexEntry) -> Manifest:
        return Manifest.model_validate_json((self.root / entry.path).read_text())


def case_summary(m: Manifest) -> dict[str, Any]:
    """What load_case returns to the Orchestrator. Mirrors the viewer's caseSummary."""
    assets: list[dict[str, Any]] = []
    for a in m.assets:
        if isinstance(a, TumorAsset):
            assets.append(
                {
                    "id": a.id,
                    "kind": a.kind,
                    "label": a.label,
                    "volume_ml": a.volume_ml,
                    "centroid_ras": list(a.centroid_ras),
                    "bbox_ras": [list(a.bbox_ras[0]), list(a.bbox_ras[1])],
                    "min_dist_surface_mm": a.min_dist_surface_mm,
                    "hemisphere": hemisphere_of(a.centroid_ras[0], m.midline_x_ras),
                }
            )
        else:
            assets.append({"id": a.id, "kind": a.kind})
    return {
        "case_id": m.case_id,
        "provenance": m.provenance,
        "dims": list(m.dims),
        "midline_x_ras": m.midline_x_ras,
        "assets": assets,
        "dice_vs_gt": m.metrics.dice_vs_gt,
    }
```

```python
"""Backend validation of scene tool arguments (spec §5). Mirrors the viewer's zod schemas.

Unknown asset ids raise ValueError, which Strands returns to the Orchestrator as an error tool result.
Numeric ranges are clamped, never rejected.
"""
import math

import numpy as np

from ..manifest import Manifest

# Canonical RAS volumes: voxel axis i/j/k runs along RAS x/y/z.
AXIS_DIM = {"sagittal": 0, "coronal": 1, "axial": 2}


def clamp(value: float, lo: float, hi: float) -> float:
    return min(hi, max(lo, value))


def check_asset_ids(m: Manifest, ids: list[str]) -> list[str]:
    if not ids:
        raise ValueError("asset_ids must not be empty")
    known = [a.id for a in m.assets]
    for i in ids:
        if i not in known:
            raise ValueError(f"unknown asset_id {i!r}; expected one of {', '.join(known)}")
    return ids


def ras_extent(m: Manifest) -> tuple[list[float], list[float]]:
    """RAS min and max over the voxel-centre corners, like the viewer's rasExtent."""
    a = np.asarray(m.vox2ras, dtype=float).reshape(4, 4)
    di, dj, dk = (d - 1 for d in m.dims)
    corners = np.array([[i, j, k, 1.0] for i in (0, di) for j in (0, dj) for k in (0, dk)])
    ras = (corners @ a.T)[:, :3]
    return ras.min(axis=0).tolist(), ras.max(axis=0).tolist()


def clamp_cut_mm(m: Manifest, plane: str, ras_mm: float) -> float:
    lo, hi = ras_extent(m)
    d = AXIS_DIM[plane]
    return clamp(ras_mm, lo[d], hi[d])


def clamp_slice_index(m: Manifest, axis: str, index: float) -> int:
    """Round half up (JavaScript Math.round), then clamp to the slice count."""
    count = m.dims[AXIS_DIM[axis]]
    return int(clamp(math.floor(index + 0.5), 0, count - 1))
```

```python
"""Scene tool calls travel to the browser over the WebSocket and come back as tool results (spec §5 Transport)."""
import asyncio
import uuid
from collections.abc import Awaitable, Callable
from typing import Any

Send = Callable[[dict[str, Any]], Awaitable[None]]
DEFAULT_TIMEOUT_S = 10.0


class BrowserToolError(ValueError):
    """The browser refused or failed a tool call. Strands returns it to the Orchestrator as an error result."""


class BrowserBridge:
    def __init__(self, send: Send):
        self._send = send
        self._pending: dict[str, asyncio.Future[dict[str, Any]]] = {}
        self._closed: str | None = None

    async def call(self, name: str, args: dict[str, Any], timeout_s: float = DEFAULT_TIMEOUT_S) -> Any:
        """Run one tool in the browser. Returns its result, or raises BrowserToolError."""
        if self._closed:
            raise BrowserToolError(self._closed)
        call_id = f"srv-{uuid.uuid4().hex[:12]}"
        future: asyncio.Future[dict[str, Any]] = asyncio.get_running_loop().create_future()
        self._pending[call_id] = future
        try:
            await self._send({"type": "tool_call", "id": call_id, "name": name, "args": args})
            reply = await asyncio.wait_for(future, timeout_s)
        except TimeoutError:
            raise BrowserToolError(f"the browser did not answer {name} within {timeout_s:g} s") from None
        finally:
            self._pending.pop(call_id, None)
        if reply.get("ok"):
            return reply.get("result")
        raise BrowserToolError(str(reply.get("error") or f"{name} failed in the browser"))

    def resolve(self, reply: dict[str, Any]) -> bool:
        """Deliver a tool_result from the browser. False if no call is waiting for that id."""
        future = self._pending.get(str(reply.get("id")))
        if future is None or future.done():
            return False
        future.set_result(reply)
        return True

    def close(self, reason: str) -> None:
        """Fail every waiting call, and every later one, with `reason`."""
        self._closed = reason
        for future in self._pending.values():
            if not future.done():
                future.set_exception(BrowserToolError(reason))
        self._pending.clear()
```

```python
"""Test doubles for the agent server: a scripted Strands model and a recording browser bridge."""
import json
from typing import Any

from strands.models.model import Model


class ScriptedModel(Model):
    """Replays scripted assistant turns instead of calling a provider.

    Each turn is a list of parts: ("text", str) or ("tool", name, input_dict).
    `seen` records what the agent sent on every call.
    """

    def __init__(self, turns: list[list[tuple]]):
        self.turns = list(turns)
        self.seen: list[dict[str, Any]] = []

    def update_config(self, **model_config: Any) -> None:
        pass

    def get_config(self) -> dict[str, Any]:
        return {"model_id": "scripted"}

    async def structured_output(self, *args: Any, **kwargs: Any):
        raise NotImplementedError
        yield

    async def stream(self, messages, tool_specs=None, system_prompt=None, **kwargs):
        self.seen.append(
            {"messages": messages, "tools": [t["name"] for t in tool_specs or []], "system": system_prompt}
        )
        turn = self.turns.pop(0)
        yield {"messageStart": {"role": "assistant"}}
        stop = "end_turn"
        for i, part in enumerate(turn):
            if part[0] == "text":
                yield {"contentBlockStart": {"start": {}}}
                yield {"contentBlockDelta": {"delta": {"text": part[1]}}}
                yield {"contentBlockStop": {}}
            else:
                stop = "tool_use"
                yield {"contentBlockStart": {"start": {"toolUse": {"toolUseId": f"tu{i}", "name": part[1]}}}}
                yield {"contentBlockDelta": {"delta": {"toolUse": {"input": json.dumps(part[2])}}}}
                yield {"contentBlockStop": {}}
        yield {"messageStop": {"stopReason": stop}}


def tool_results(model: ScriptedModel, call: int) -> list[dict]:
    """The toolResult blocks the agent sent to the model on call number `call` (0-based)."""
    return [b["toolResult"] for msg in model.seen[call]["messages"] for b in msg["content"] if "toolResult" in b]


class RecordingBridge:
    """Stands in for BrowserBridge: records calls and answers with `results[name]` (default: echo args)."""

    def __init__(self, results: dict[str, Any] | None = None, fail: dict[str, str] | None = None):
        self.calls: list[tuple[str, dict]] = []
        self.results = results or {}
        self.fail = fail or {}

    async def call(self, name: str, args: dict, timeout_s: float = 10.0) -> Any:
        from jarvis_neuro.agent.bridge import BrowserToolError

        self.calls.append((name, args))
        if name in self.fail:
            raise BrowserToolError(self.fail[name])
        return self.results.get(name, args)
```

```python
"""The Clinical Reasoner: a Strands sub-agent reached only through `explain` (spec §5 Roles)."""
import json
from collections.abc import Awaitable, Callable
from typing import Any

from strands import Agent
from strands.models.model import Model

from ..manifest import Manifest, TumorAsset
from .cases import hemisphere_of

Explainer = Callable[[str, Manifest], Awaitable[str]]

# The scripted answer for anatomy, function and risk questions (spec §1, consequences of decision 1).
ATLAS_ANSWER = (
    "Unknown. That needs atlas registration, which this build does not do: "
    "the surface shown is this patient's own scan and has no named regions."
)

LABEL_MEANING = {
    "tumor_et": "enhancing tumor (MSD label 3)",
    "tumor_ncr": "non-enhancing tumor (MSD label 2)",
    "tumor_ed": "edema (MSD label 1)",
}

REASONER_PROMPT = f"""You are the Clinical Reasoner in Jarvis-Neuro, an educational 3D viewer of one brain MRI case
for medical students. It is not for diagnosis or surgical planning.

You receive a question and CASE FACTS, a JSON object copied from the case's manifest.json.

Rules:
- State only facts present in CASE FACTS or arithmetic on them (sums, comparisons, rounding): volumes in mL,
  centroids and bounding boxes in RAS millimetres, hemisphere, distance to the brain surface in mm, provenance
  (ground-truth labels or the MONAI SegResNet model), and Dice against ground truth when it is present.
- RAS means +x patient right, +y anterior, +z superior.
- If the question asks about anatomy, named regions, lobes, function, eloquent cortex, prognosis, risk, grading,
  treatment or surgery, answer with exactly this sentence and nothing else:
  {ATLAS_ANSWER}
- If a needed fact is missing, say it is not in the case data. Never estimate or invent a number.
- Answer in at most three short sentences. The answer is read aloud.
"""


def case_facts(m: Manifest) -> dict[str, Any]:
    tumours = [
        {
            "id": a.id,
            "meaning": LABEL_MEANING[a.id],
            "volume_ml": a.volume_ml,
            "centroid_ras": list(a.centroid_ras),
            "bbox_ras": [list(a.bbox_ras[0]), list(a.bbox_ras[1])],
            "hemisphere": hemisphere_of(a.centroid_ras[0], m.midline_x_ras),
            "min_dist_surface_mm": a.min_dist_surface_mm,
        }
        for a in m.assets
        if isinstance(a, TumorAsset)
    ]
    return {
        "case_id": m.case_id,
        "provenance": m.provenance,
        "midline_x_ras": m.midline_x_ras,
        "tumour_sub_regions": tumours,
        "dice_vs_gt": m.metrics.dice_vs_gt,
    }


def reasoner_input(question: str, m: Manifest) -> str:
    return f"QUESTION: {question}\n\nCASE FACTS:\n{json.dumps(case_facts(m), indent=2)}"


def make_explainer(model: Model) -> Explainer:
    async def explain(question: str, m: Manifest) -> str:
        # A fresh agent per question: the Reasoner keeps no memory between calls.
        reasoner = Agent(model=model, system_prompt=REASONER_PROMPT, callback_handler=None)
        result = await reasoner.invoke_async(reasoner_input(question, m))
        return str(result).strip()

    return explain
```

```python
from strands import tool

from ..manifest import Manifest
from .bridge import BrowserBridge
from .cases import CaseRepo, case_summary
from .reasoner import Explainer
from .scene_args import check_asset_ids, clamp, clamp_cut_mm, clamp_slice_index

LOAD_TIMEOUT_S = 30.0

Provenance = Literal["ground-truth", "monai-segresnet", "synthetic"]
Plane = Literal["axial", "coronal", "sagittal", "none"]
Side = Literal["left", "right", "none"]
Axis = Literal["axial", "coronal", "sagittal"]


@dataclass
class SceneContext:
    """Per-connection state the tools share. `manifest` is the case the browser shows."""

    bridge: BrowserBridge
    repo: CaseRepo
    manifest: Manifest | None = None

    def require_case(self) -> Manifest:
        if self.manifest is None:
            raise ValueError("no case loaded; call load_case first")
        return self.manifest

    def set_case(self, case_id: str, provenance: str | None) -> Manifest:
        self.manifest = self.repo.manifest(self.repo.entry(case_id, provenance))
        return self.manifest


def make_tools(ctx: SceneContext, explainer: Explainer) -> list[Any]:
    @tool
    async def load_case(case_id: str, provenance: Provenance | None = None) -> dict:
        """Load a baked case into the viewer and return its manifest summary.

        Args:
            case_id: Case id from the case index, for example brats_001.
            provenance: ground-truth (expert labels) or monai-segresnet (model output). Omit for the default.
        """
        entry = ctx.repo.entry(case_id, provenance)
        manifest = ctx.repo.manifest(entry)
        args = {"case_id": entry.case_id, "provenance": entry.provenance}
        await ctx.bridge.call("load_case", args, timeout_s=LOAD_TIMEOUT_S)
        ctx.manifest = manifest
        return case_summary(manifest)

    @tool
    async def set_opacity(asset_id: str, value: float) -> Any:
        """Set one asset's opacity.

        Args:
            asset_id: An asset id from load_case, for example brain_surface or tumor_et.
            value: Opacity from 0 (invisible) to 1 (opaque). Out-of-range values are clamped.
        """
        check_asset_ids(ctx.require_case(), [asset_id])
        return await ctx.bridge.call("set_opacity", {"asset_id": asset_id, "value": clamp(value, 0, 1)})

    @tool
    async def focus_region(asset_id: str) -> Any:
        """Fit the camera to an asset's bounding box. Selecting a tumour sub-region also moves the MRI slice to it.

        Args:
            asset_id: An asset id from load_case.
        """
        check_asset_ids(ctx.require_case(), [asset_id])
        return await ctx.bridge.call("focus_region", {"asset_id": asset_id})

    @tool
    async def set_cutaway(plane: Plane, ras_mm: float | None = None) -> Any:
        """Cut every asset with a plane. Use plane none to remove the cut.

        Args:
            plane: axial, coronal, sagittal or none.
            ras_mm: Plane position in RAS millimetres. Required unless plane is none. Copy it from a
                centroid_ras or bbox_ras value in the load_case result; never invent it.
        """
        m = ctx.require_case()
        if plane == "none":
            return await ctx.bridge.call("set_cutaway", {"plane": "none"})
        if ras_mm is None:
            raise ValueError("ras_mm is required unless plane is none")
        return await ctx.bridge.call("set_cutaway", {"plane": plane, "ras_mm": clamp_cut_mm(m, plane, ras_mm)})

    @tool
    async def hide_hemisphere(side: Side) -> Any:
        """Hide one half of brain_surface, split at the case midline. Use none to show both.

        Args:
            side: left, right or none (patient left and right).
        """
        ctx.require_case()
        return await ctx.bridge.call("hide_hemisphere", {"side": side})

    @tool
    async def set_explode(value: float) -> Any:
        """Pull the brain apart: the hemispheres and tumour sub-regions move away from each other.

        Args:
            value: 0 (assembled) to 1 (fully apart). Out-of-range values are clamped.
        """
        ctx.require_case()
        return await ctx.bridge.call("set_explode", {"value": clamp(value, 0, 1)})

    @tool
    async def toggle_visibility(asset_ids: list[str], visible: bool) -> Any:
        """Show or hide assets.

        Args:
            asset_ids: One or more asset ids from load_case.
            visible: true to show, false to hide.
        """
        check_asset_ids(ctx.require_case(), asset_ids)
        return await ctx.bridge.call("toggle_visibility", {"asset_ids": asset_ids, "visible": visible})

    @tool
    async def inspect_mri_slice(axis: Axis, index: int) -> Any:
        """Show one MRI slice in the 2D panel and list the mask labels present in it.

        Args:
            axis: axial, coronal or sagittal.
            index: Slice index along that axis. Out-of-range values are clamped to the volume.
        """
        m = ctx.require_case()
        return await ctx.bridge.call("inspect_mri_slice", {"axis": axis, "index": clamp_slice_index(m, axis, index)})

    @tool
    async def explain(question: str) -> str:
        """Answer a question about the loaded case with the Clinical Reasoner. It uses manifest facts only.

        Args:
            question: The user's question, in their words.
        """
        return await explainer(question, ctx.require_case())

    return [
        load_case,
        set_opacity,
        focus_region,
        set_cutaway,
        hide_hemisphere,
        set_explode,
        toggle_visibility,
        inspect_mri_slice,
        explain,
    ]
```

```python
"""WebSocket messages from the browser, validated with pydantic. Server messages are plain dicts:

{"type": "status", "state": "ready" | "unavailable", "detail": str | None}
{"type": "busy", "busy": bool}
{"type": "tool_call", "id": str, "name": str, "args": dict}
{"type": "reply", "turn_id": str, "text": str}
{"type": "error", "turn_id": str | None, "message": str}
"""
from typing import Annotated, Any, Literal, Union

from pydantic import BaseModel, ConfigDict, Field, TypeAdapter


class _Msg(BaseModel):
    model_config = ConfigDict(extra="forbid")


class UserMessage(_Msg):
    type: Literal["user"]
    turn_id: Annotated[str, Field(min_length=1, max_length=64)]
    text: Annotated[str, Field(min_length=1, max_length=2000)]


class ToolResultMessage(_Msg):
    type: Literal["tool_result"]
    id: str
    ok: bool
    result: Any = None
    error: str | None = None


class CaseMessage(_Msg):
    """The case the viewer shows, sent on connect and whenever it changes (keyboard, gestures or the agent)."""

    type: Literal["case"]
    case_id: str
    provenance: str


ClientMessage = Annotated[Union[UserMessage, ToolResultMessage, CaseMessage], Field(discriminator="type")]
CLIENT_MESSAGE = TypeAdapter(ClientMessage)
```

```python
"""The Orchestrator: one Strands agent per browser connection, holding every tool (spec §5 Roles)."""
import asyncio

from strands import Agent
from strands.models.model import Model

from .reasoner import Explainer
from .tools import SceneContext, make_tools

ORCHESTRATOR_PROMPT = """You are Jarvis, the voice assistant of Jarvis-Neuro, an educational 3D viewer of one brain
MRI case for medical students. It is not for diagnosis or surgical planning.

You control the viewer only through your tools. The user sees the result on screen.

Rules:
- Every number you say must come from a tool result. Never invent a volume, a coordinate or a slice index.
- Asset ids are brain_surface, tumor_et (enhancing tumor), tumor_ncr (non-enhancing tumor) and tumor_ed (edema).
  There are no named brain regions in this build.
- For set_cutaway, take ras_mm from a centroid_ras or bbox_ras value in the load_case result.
  RAS components are x (patient right), y (anterior), z (superior): sagittal uses x, coronal y, axial z.
- For inspect_mri_slice, prefer focus_region on a tumour sub-region, which moves the slice for you. Use an index
  only from a previous inspect_mri_slice result or when the user names one.
- Questions about the case's findings, meaning, anatomy, function or risk go to explain. Repeat its answer.
- If a tool returns an error, say in one short sentence that you could not do it and why.
- If no case is loaded, call load_case first.
- Reply in at most two short sentences. Replies are read aloud.
"""


class OrchestratorSession:
    def __init__(self, ctx: SceneContext, model: Model, explainer: Explainer):
        self.ctx = ctx
        self.agent = Agent(
            model=model,
            tools=make_tools(ctx, explainer),
            system_prompt=ORCHESTRATOR_PROMPT,
            callback_handler=None,
        )
        # A Strands agent runs one invocation at a time; later messages wait their turn.
        self._lock = asyncio.Lock()

    async def ask(self, text: str) -> str:
        async with self._lock:
            result = await self.agent.invoke_async(text)
        return str(result).strip()
```

```python
"""FastAPI app: the agent WebSocket at /ws, a health check, and the built viewer (spec decision 7).

Run: uv run uvicorn jarvis_neuro.agent.app:app --port 8000
"""
import asyncio
import logging
from collections.abc import Callable
from pathlib import Path
from typing import Any

from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.middleware.gzip import GZipMiddleware
from fastapi.staticfiles import StaticFiles
from pydantic import ValidationError
from strands.models.model import Model

from .bridge import BrowserBridge
from .cases import REPO_ROOT, CaseRepo
from .config import AgentSettings, ConfigError, build_model, load_settings
from .orchestrator import OrchestratorSession
from .protocol import CLIENT_MESSAGE, CaseMessage, ToolResultMessage, UserMessage
from .reasoner import make_explainer
from .tools import SceneContext

log = logging.getLogger(__name__)
DEFAULT_STATIC_DIR = REPO_ROOT / "frontend" / "dist"
ModelBuilder = Callable[[AgentSettings, str], Model]


def create_app(
    *,
    settings_loader: Callable[[], AgentSettings] = load_settings,
    model_builder: ModelBuilder = build_model,
    repo: CaseRepo | None = None,
    static_dir: Path | None = DEFAULT_STATIC_DIR,
) -> FastAPI:
    app = FastAPI(title="Jarvis-Neuro agent")
    app.add_middleware(GZipMiddleware, minimum_size=1024)
    cases = repo or CaseRepo()

    def agent_state() -> tuple[AgentSettings | None, str | None]:
        try:
            return settings_loader(), None
        except ConfigError as e:
            return None, str(e)

    @app.get("/api/health")
    def health() -> dict[str, Any]:
        settings, problem = agent_state()
        return {"ok": True, "agent": "ready" if settings else "unavailable", "detail": problem}

    @app.websocket("/ws")
    async def agent_socket(socket: WebSocket) -> None:
        await socket.accept()
        send_lock = asyncio.Lock()

        async def send(msg: dict[str, Any]) -> None:
            async with send_lock:
                await socket.send_json(msg)

        settings, problem = agent_state()
        bridge = BrowserBridge(send)
        ctx = SceneContext(bridge=bridge, repo=cases)
        session = None
        if settings:
            session = OrchestratorSession(
                ctx,
                model_builder(settings, settings.orchestrator_model),
                make_explainer(model_builder(settings, settings.reasoner_model)),
            )
        await send({"type": "status", "state": "ready" if session else "unavailable", "detail": problem})

        async def run_turn(msg: UserMessage) -> None:
            await send({"type": "busy", "busy": True})
            try:
                text = await session.ask(msg.text)
                await send({"type": "reply", "turn_id": msg.turn_id, "text": text})
            except Exception as e:  # provider down, quota, bad key: tell the user, keep the socket
                log.exception("agent turn failed")
                await send({"type": "error", "turn_id": msg.turn_id, "message": f"agent failed: {e}"})
            finally:
                await send({"type": "busy", "busy": False})

        turns: set[asyncio.Task[None]] = set()
        try:
            while True:
                raw = await socket.receive_json()
                try:
                    msg = CLIENT_MESSAGE.validate_python(raw)
                except ValidationError as e:
                    await send({"type": "error", "turn_id": None, "message": f"bad message: {e.errors()[0]['msg']}"})
                    continue
                if isinstance(msg, ToolResultMessage):
                    bridge.resolve(msg.model_dump())
                elif isinstance(msg, CaseMessage):
                    try:
                        ctx.set_case(msg.case_id, msg.provenance)
                    except (ValueError, OSError) as e:
                        ctx.manifest = None
                        await send({"type": "error", "turn_id": None, "message": f"case sync failed: {e}"})
                elif session is None:
                    await send({"type": "error", "turn_id": msg.turn_id, "message": f"agent unavailable: {problem}"})
                else:
                    task = asyncio.create_task(run_turn(msg))
                    turns.add(task)
                    task.add_done_callback(turns.discard)
        except WebSocketDisconnect:
            pass
        finally:
            bridge.close("the browser disconnected")
            for task in turns:
                task.cancel()

    if static_dir is not None and static_dir.is_dir():
        app.mount("/", StaticFiles(directory=static_dir, html=True), name="viewer")
    return app


app = create_app()
```

```ts
import { z } from 'zod'
import type { Provenance } from '../lib/manifest'

/** Messages the agent server sends. Mirrors backend/src/jarvis_neuro/agent/protocol.py. */
export const ServerMessageSchema = z.discriminatedUnion('type', [
  z.object({ type: z.literal('status'), state: z.enum(['ready', 'unavailable']), detail: z.string().nullable() }),
  z.object({ type: z.literal('busy'), busy: z.boolean() }),
  z.object({ type: z.literal('tool_call'), id: z.string(), name: z.string(), args: z.unknown() }),
  z.object({ type: z.literal('reply'), turn_id: z.string(), text: z.string() }),
  z.object({ type: z.literal('error'), turn_id: z.string().nullable(), message: z.string() }),
])
export type ServerMessage = z.infer<typeof ServerMessageSchema>

/** Messages the browser sends. The backend validates them with pydantic (extra keys rejected). */
export type ClientMessage =
  | { type: 'user'; turn_id: string; text: string }
  | { type: 'tool_result'; id: string; ok: true; result: unknown }
  | { type: 'tool_result'; id: string; ok: false; error: string }
  | { type: 'case'; case_id: string; provenance: Provenance }

/** A WebSocket frame to a server message, or null if it is not one. */
export function parseServerMessage(data: unknown): ServerMessage | null {
  if (typeof data !== 'string') return null
  let json: unknown
  try {
    json = JSON.parse(data)
  } catch {
    return null
  }
  const r = ServerMessageSchema.safeParse(json)
  return r.success ? r.data : null
}
```

```ts
import { type ClientMessage, type ServerMessage, parseServerMessage } from './protocol'

export type LinkEvent = 'connecting' | 'open' | 'closed'

/** The part of WebSocket the connection uses, so tests can pass a fake. */
export interface SocketLike {
  readonly readyState: number
  send(data: string): void
  close(): void
  onopen: (() => void) | null
  onmessage: ((e: { data: unknown }) => void) | null
  onclose: (() => void) | null
  onerror: (() => void) | null
}

export interface ConnectionDeps {
  open(url: string): SocketLike
  schedule(fn: () => void, ms: number): unknown
  cancel(handle: unknown): void
}

export interface ConnectionHandlers {
  message(msg: ServerMessage): void
  link(event: LinkEvent): void
}

const OPEN = 1
export const BACKOFF_BASE_MS = 500
export const BACKOFF_MAX_MS = 10_000

/** Reconnect delay after `attempt` failed tries: 0.5 s, 1 s, 2 s ... capped at 10 s (spec §7). */
export function backoffMs(attempt: number): number {
  return Math.min(BACKOFF_MAX_MS, BACKOFF_BASE_MS * 2 ** attempt)
}

export function browserDeps(): ConnectionDeps {
  return {
    // WebSocket's handlers take typed events; the connection only sets them, so the narrower interface is safe.
    open: (url) => new WebSocket(url) as unknown as SocketLike,
    schedule: (fn, ms) => setTimeout(fn, ms),
    cancel: (handle) => clearTimeout(handle as ReturnType<typeof setTimeout>),
  }
}

/** One WebSocket to the agent server that reconnects with backoff until stopped. */
export class AgentConnection {
  private socket: SocketLike | null = null
  private attempt = 0
  private timer: unknown = null
  private stopped = true

  constructor(
    private readonly url: string,
    private readonly on: ConnectionHandlers,
    private readonly deps: ConnectionDeps = browserDeps(),
  ) {}

  start(): void {
    if (!this.stopped) return
    this.stopped = false
    this.connect()
  }

  stop(): void {
    this.stopped = true
    if (this.timer !== null) this.deps.cancel(this.timer)
    this.timer = null
    const s = this.socket
    this.socket = null
    s?.close()
    this.on.link('closed')
  }

  /** False when there is no open socket; the message is dropped, not queued. */
  send(msg: ClientMessage): boolean {
    if (!this.socket || this.socket.readyState !== OPEN) return false
    this.socket.send(JSON.stringify(msg))
    return true
  }

  private connect(): void {
    this.on.link('connecting')
    const s = this.deps.open(this.url)
    this.socket = s
    s.onopen = () => {
      this.attempt = 0
      this.on.link('open')
    }
    s.onmessage = (e) => {
      const msg = parseServerMessage(e.data)
      if (msg) this.on.message(msg)
      else console.warn('[agent] ignored a malformed server message')
    }
    s.onerror = () => {} // a close event always follows
    s.onclose = () => {
      if (this.socket !== s) return
      this.socket = null
      this.on.link('closed')
      if (this.stopped) return
      this.timer = this.deps.schedule(() => {
        this.timer = null
        this.connect()
      }, backoffMs(this.attempt++))
    }
  }
}
```

```ts
import type { ViewerStore } from '../state/store'
import { executeTool, newCallId } from '../tools/execute'
import type { ConnectionHandlers } from './connection'
import type { ClientMessage, ServerMessage } from './protocol'

/** What the client needs from AgentConnection; tests pass a fake. */
export interface Transport {
  start(): void
  stop(): void
  send(msg: ClientMessage): boolean
}

export interface AgentClient {
  /** Sends one user turn. False (and an error line in the transcript) when the agent is not online. */
  sendUser(text: string): boolean
  stop(): void
}

export const NOT_CONNECTED = 'The agent is not connected. Mouse, keyboard and gestures still work.'

/** Wires the agent socket to the viewer store: runs forwarded tool calls, keeps the server's case in sync, records the transcript. */
export function startAgentClient(
  store: ViewerStore,
  makeTransport: (on: ConnectionHandlers) => Transport,
  speak: (text: string) => void,
): AgentClient {
  const s = () => store.getState()
  const note = (role: 'user' | 'agent' | 'error', text: string) =>
    s().addTranscript({ id: newCallId(role), role, text, at: Date.now() })

  const sendCase = () => {
    const c = s().current
    if (c) transport.send({ type: 'case', case_id: c.manifest.case_id, provenance: c.manifest.provenance })
  }

  const onMessage = async (msg: ServerMessage) => {
    switch (msg.type) {
      case 'status':
        s().setAgent({ link: msg.state === 'ready' ? 'online' : 'unavailable', detail: msg.detail })
        return
      case 'busy':
        s().setAgent({ busy: msg.busy })
        return
      case 'tool_call': {
        const result = await executeTool(store, { id: msg.id, name: msg.name, args: msg.args }, 'agent')
        transport.send({ type: 'tool_result', ...result })
        return
      }
      case 'reply':
        note('agent', msg.text)
        if (s().agent.speakReplies) speak(msg.text)
        return
      case 'error':
        note('error', msg.message)
        return
    }
  }

  const transport = makeTransport({
    message: (msg) => void onMessage(msg),
    link(event) {
      if (event === 'closed') s().setAgent({ link: 'offline', busy: false })
      else s().setAgent({ link: 'connecting' })
      if (event === 'open') sendCase()
    },
  })

  const unsubscribe = store.subscribe((now, prev) => {
    if (now.current !== prev.current) sendCase()
  })
  transport.start()

  return {
    sendUser(raw) {
      const text = raw.trim()
      if (!text) return false
      if (s().agent.link !== 'online') {
        note('error', NOT_CONNECTED)
        return false
      }
      note('user', text)
      if (transport.send({ type: 'user', turn_id: newCallId('turn'), text: text.slice(0, 2000) })) return true
      note('error', NOT_CONNECTED)
      return false
    },
    stop() {
      unsubscribe()
      transport.stop()
    },
  }
}
```

```ts
/** Web Speech API wrappers (spec §5). lib.dom has no SpeechRecognition types, so the parts used are declared here. */

export interface RecognitionResultLike {
  readonly isFinal: boolean
  readonly 0: { readonly transcript: string }
}

export interface RecognitionEventLike {
  readonly results: ArrayLike<RecognitionResultLike>
}

export interface RecognitionLike {
  lang: string
  continuous: boolean
  interimResults: boolean
  maxAlternatives: number
  onresult: ((e: RecognitionEventLike) => void) | null
  onerror: ((e: { error: string }) => void) | null
  onend: (() => void) | null
  start(): void
  stop(): void
  abort(): void
}

export type RecognitionCtor = new () => RecognitionLike

export function recognitionCtor(g: object = globalThis): RecognitionCtor | null {
  const w = g as { SpeechRecognition?: RecognitionCtor; webkitSpeechRecognition?: RecognitionCtor }
  return w.SpeechRecognition ?? w.webkitSpeechRecognition ?? null
}

/** The final transcript of a recognition event, or '' if nothing final yet. */
export function finalText(e: RecognitionEventLike): string {
  let text = ''
  for (let i = 0; i < e.results.length; i++) {
    const r = e.results[i]
    if (r.isFinal) text += r[0].transcript
  }
  return text.trim()
}

export function speechErrorText(code: string): string | null {
  if (code === 'aborted' || code === 'no-speech') return null
  if (code === 'not-allowed' || code === 'service-not-allowed') return 'Microphone blocked; type instead.'
  return `Speech recognition failed (${code}); type instead.`
}

export interface ListenerHandlers {
  text(text: string): void
  listening(on: boolean): void
  error(message: string): void
}

export interface Listener {
  start(): void
  stop(): void
}

/** Single-shot listener: one utterance per start(), final result only. */
export function createListener(ctor: RecognitionCtor, on: ListenerHandlers, lang = 'en-US'): Listener {
  let rec: RecognitionLike | null = null
  return {
    start() {
      if (rec) return
      const r = new ctor()
      rec = r
      r.lang = lang
      r.continuous = false
      r.interimResults = false
      r.maxAlternatives = 1
      r.onresult = (e) => {
        const text = finalText(e)
        if (text) on.text(text)
      }
      r.onerror = (e) => {
        const message = speechErrorText(e.error)
        if (message) on.error(message)
      }
      r.onend = () => {
        rec = null
        on.listening(false)
      }
      try {
        r.start()
        on.listening(true)
      } catch (e) {
        rec = null
        on.error(`Speech recognition failed (${e instanceof Error ? e.message : String(e)}); type instead.`)
      }
    },
    stop() {
      rec?.stop()
    },
  }
}

export interface SynthLike {
  cancel(): void
  speak(u: unknown): void
}

/** Speaks `text`, cutting off any reply still being read out. */
export function speak(text: string, synth: SynthLike, Utterance: new (text: string) => unknown): void {
  synth.cancel()
  synth.speak(new Utterance(text))
}
```

```ts
import type { ViewerStore } from '../state/store'
import { type AgentClient, startAgentClient } from './client'
import { AgentConnection } from './connection'
import { type Listener, createListener, recognitionCtor, speak } from './speech'

/** App-wide agent client. The console and the shortcuts reach it through these functions. */
let client: AgentClient | null = null
let listener: Listener | null = null
let agentStore: ViewerStore | null = null

export function defaultAgentUrl(loc: Pick<Location, 'protocol' | 'host'> = location): string {
  return `${loc.protocol === 'https:' ? 'wss:' : 'ws:'}//${loc.host}/ws`
}

function speakReply(text: string) {
  if (typeof speechSynthesis === 'undefined' || typeof SpeechSynthesisUtterance === 'undefined') return
  speak(text, speechSynthesis, SpeechSynthesisUtterance)
}

export function startAgent(store: ViewerStore, url: string): void {
  if (client) return
  agentStore = store
  client = startAgentClient(store, (on) => new AgentConnection(url, on), speakReply)
  const ctor = recognitionCtor()
  listener = ctor
    ? createListener(ctor, {
        text: (t) => void client?.sendUser(t),
        listening: (on) => store.getState().setAgent({ listening: on }),
        error: (message) => store.getState().addTranscript({ id: `mic-${Date.now()}`, role: 'error', text: message, at: Date.now() }),
      })
    : null
}

export function sendText(text: string): boolean {
  return client?.sendUser(text) ?? false
}

export const voiceSupported = (): boolean => recognitionCtor() !== null

/** Push-to-talk toggle for the mic button and the V key. */
export function toggleVoice(): void {
  if (!listener || !agentStore) return
  if (agentStore.getState().agent.listening) listener.stop()
  else listener.start()
}
```

````markdown
Python 3.12, managed with `uv`. Two parts:

## How a turn works

1. The browser sends `{type:"user", text}`.
2. The Orchestrator picks tools. Each tool validates and clamps its arguments against the loaded manifest, then sends `{type:"tool_call"}` to the browser.
3. The browser runs the call through the same `executeTool` the keyboard uses and answers `{type:"tool_result", ok, result|error}`. Errors go back to the model as tool errors.
4. `explain` asks the Clinical Reasoner, which sees the question plus the manifest facts and nothing else.
5. The server sends `{type:"reply", text}`; the browser shows it and speaks it.
````

````markdown
## Agent

`src/agent/` connects to the agent server (`../backend`, `uv run uvicorn jarvis_neuro.agent.app:app --port 8000`) over one WebSocket. `npm run dev` proxies `/ws` and `/api` to port 8000; `VITE_AGENT_URL` overrides the socket URL. The socket reconnects with backoff (0.5 s doubling to 10 s). Mouse, keyboard and gestures never wait for it.

The Agent console shows the link state (online, connecting, offline, unavailable with the server's reason on hover), the conversation, a text box, a mic button (`v`) and a "Speak replies" switch. Voice uses the Web Speech API: Chrome sends the audio to Google's servers for recognition; replies are read out with `speechSynthesis`. Where speech recognition is missing, the mic is disabled and the text box works.

The server sends scene tool calls to the browser. `executeTool(store, { id, name, args }, source)` in `src/tools/execute.ts` runs them, like every other input: it validates `args` with zod, rejects unknown asset ids and keys, clamps numeric ranges, logs the call in the Agent console and returns `{ id, ok: true, result }` or `{ id, ok: false, error }`, which goes back to the Orchestrator. Dev builds expose it in the console:

```js
await __jarvis.executeTool(__jarvis.store, { id: 'x', name: 'focus_region', args: { asset_id: 'tumor_et' } })
```

Browser tools: `load_case`, `set_opacity`, `focus_region`, `set_cutaway`, `hide_hemisphere`, `set_explode`, `toggle_visibility`, `inspect_mri_slice`. `explain` runs on the server only (the Clinical Reasoner).
````
